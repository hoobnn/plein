Where storiesunfold

Plein is an open-source AI infinite canvas. Start from a single idea, lay out the script, characters, storyboard, shots and voiceover on the canvas, and turn them into a short drama together with an AI agent. Every step stays visible and editable, and if one shot is off you redo just that shot.

Download for macOS View source on GitHub

Free and open source. Runs on Apple silicon Macs, or self-host it with Docker. The app UI is in Simplified Chinese for now.

Why Plein

Review before you spend
Inserting the short drama template only builds the skeleton and never calls a model on its own. Review the storyboard and shot images first, then generate video and voiceover in batches.
Change one thing, redo one thing
Any shot can switch candidates, regenerate or be replaced by hand. Unchanged nodes hit the cache, so you never pay twice.
Your data stays on your machine
One local server, one SQLite file, one asset folder. API keys stay on your machine and never reach the browser.
Let AI operate the canvas
The built-in agent reads the canvas, creates nodes and batch-generates the storyboard. You can also hand the work to Claude Code or Codex on your machine, or drive the canvas from Cursor over MCP.

Works with Volcengine Ark, Doubao Speech, Alibaba Cloud Model Studio and MiniMax. Node parameters adapt to the model you pick.

FAQ

What is Plein?

Plein is an open-source AI tool for making short dramas, built around an infinite canvas: idea, script, characters, storyboard, shot images, video, voiceover and the final cut are wired nodes on the canvas, generated step by step by the models you connect, and every step can be reviewed, edited and re-run on its own.

Is Plein free?

Plein itself is free and open source under AGPL-3.0. Images, video and voiceover are generated with your own model platform accounts, which bill you by usage. Unchanged nodes reuse the cache, so you are never charged twice for the same result.

Which AI models does Plein support?

Four platforms are built in: Volcengine Ark (Doubao Seed chat, Seedream images, Seedance video), Doubao Speech (text to speech, Seed Audio music and sound effects), Alibaba Cloud Model Studio (Qwen, Qwen Image, Wan image and video, Qwen TTS) and MiniMax (M-series chat, image-01, H3 video, speech and music). You choose the model for each capability, and new platforms can be added with plugins.

What systems does Plein run on?

Apple silicon Macs on macOS 12 or later can install the desktop app, which is signed and notarized by Apple, ships with ffmpeg and updates itself. On other systems, self-host it with Docker on your computer or server and open localhost:8787 in a browser.

Where are my scripts and assets stored?

On your own computer: one SQLite database and one asset folder, which you can back up or copy to another machine. Plein has no cloud account, and model platform API keys stay in the local server and never reach the browser.

How is Plein different from one-click video generation?

One-click generation hides the steps in between, so if you don't like the result you start over. Plein keeps every step's output on the canvas: review the storyboard and shot images before paying for video and voiceover, and when you change the script, a line or a character, it lists the affected shots and redoes only the ones you tick.

Can an AI agent operate the canvas for me?

Yes. The built-in agent reads the canvas, creates nodes and batch-generates the storyboard. You can also hand the work to Claude Code or Codex signed in on your machine, or let Cursor and Claude Desktop drive the canvas over MCP. Change plans proposed by an agent run only after you approve them.
