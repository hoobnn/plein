把一部短剧摊在一张画布上

Plein 是开源的 AI 无限画布，为短剧创作而生。剧本、角色、分镜、镜头、配音和成片都是画布上连好线的节点，每一步都看得见、改得动，哪个镜头不满意就只重做那一个。

下载 macOS 版 在 GitHub 查看源码

免费开源，支持 Apple 芯片的 Mac，也可以用 Docker 自部署。

为什么用 Plein

先审核，再付费生成
插入短剧模板只搭骨架，不会自动调用模型。先审分镜和镜头图，再分批生成视频和配音。
改一处，只重做一处
任何一个镜头都能换候选、重新生成或手动替换。没改动的节点直接用缓存，不重复扣费。
数据在你自己电脑上
一个本地服务、一个 SQLite 文件、一个素材目录。平台密钥只存在本机，不进浏览器。
由 AI 代为操作
内置智能体「小满」可以读取画布、创建节点、批量生成分镜；也可以交给本机的 Claude Code、Codex，或通过 MCP 从 Cursor 操作画布。

已接入 火山方舟、豆包语音、阿里云百炼、MiniMax，节点参数按所选模型自动给出。

常见问题

Plein 是什么？

Plein 是一款开源的 AI 短剧创作工具，核心是一张无限画布：创意、剧本、角色、分镜、镜头图、视频、配音和成片都是画布上连好线的节点，由你接入的大模型逐步生成，每一步都能查看、修改和单独重做。

Plein 收费吗？

Plein 本身免费，以 AGPL-3.0 开源。生成图片、视频和配音时使用你自己在模型平台开通的账号，费用由平台按用量收取；没有改动的节点直接复用缓存，不会重复计费。

Plein 支持哪些 AI 模型？

已接入四家平台：火山方舟（Doubao Seed 对话、Seedream 图片、Seedance 视频）、豆包语音（语音合成、Seed Audio 音乐音效）、阿里云百炼（千问、Qwen Image、万相图片与视频、Qwen TTS）和 MiniMax（M 系列对话、image-01、H3 视频、语音与音乐）。每种能力用哪个模型由你指定，新平台可以通过插件接入。

Plein 能在什么系统上使用？

macOS 12 及以上的 Apple 芯片 Mac 可以直接安装桌面版，安装包已签名并经 Apple 公证，自带 ffmpeg，会自动更新。其他系统可以用 Docker 在本机或服务器上自部署，浏览器打开 localhost:8787 使用。

我的剧本和素材存在哪里？

都在你自己的电脑上：一个 SQLite 数据库和一个素材目录，可以直接备份或拷贝到另一台机器。Plein 没有云端账号，模型平台密钥只保存在本机服务端，不会进入浏览器。

Plein 和一键生成视频有什么不同？

一键生成把中间过程藏起来，不满意只能整段重来。Plein 把每一步的产物留在画布上：先审分镜和镜头图，再付费生成视频和配音；改了剧本、台词或角色设定，会列出受影响的镜头，只重做你勾选的那几个。

可以让 AI 智能体代为操作画布吗？

可以。内置智能体「小满」能读取画布、创建节点、批量生成分镜；也可以交给本机已登录的 Claude Code、Codex，或通过 MCP 让 Cursor、Claude Desktop 直接操作画布。智能体提出的修改方案需要你批准后才会执行。

开始使用

macOS 桌面版

适用于 Apple 芯片的 Mac。已签名并经 Apple 公证，自带 ffmpeg，会自动检查更新。

下载安装包

Docker 自部署

在自己的电脑或服务器上运行，打开 localhost:8787 使用。

git clone https://github.com/hoobnn/plein.git && cd plein && docker compose up -d
