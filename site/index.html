把一部短剧摊在一张画布上

Plein 是本地优先的 AI 无限画布，为短剧创作而生。剧本、角色、分镜、镜头、配音和成片都是画布上连好线的节点，每一步都看得见、改得动，哪个镜头不满意就只重做那一个。

下载 macOS 版 在 GitHub 查看源码

免费开源，支持 Apple 芯片的 Mac，也可以用 Docker 自部署。

一部样片是这样做出来的

上面的《不是自杀》从一句创意开始，在一张画布上走完七步。每一步的产物都留在画布上，可以单独修改，下游会提示哪些需要重跑。

  1. 创意第 1 步

    快递员在雨夜天台捡到一个上锁的铁盒，从此被卷进一桩旧案。

  2. 剧本第 2 步

    对话模型按场次写成竖屏剧本，开头三秒有冲突，结尾留钩子。

    纸条上写着：不是自杀。

  3. 设定卡第 3 步
  4. 分镜第 4 步
    画面 台词
    天台，黑衣人逼近 你谁啊？
    铁盒里掉出纸条 —
    出租屋门外 晚晚，开门。
  5. 镜头第 5 步
  6. 配音第 6 步

    每句台词按角色绑定的音色单独生成，可以逐句重配。

  7. 成片第 7 步

    序列编辑器排好镜头、对白和字幕，导出竖屏 MP4。

样片使用阿里云百炼和豆包语音生成，画面和声音均未经后期修饰。

为什么用 Plein

先审再花钱
插入短剧模板只搭骨架，不会自动调用模型。先审分镜和镜头图，再分批生成视频和配音。
改一处，只重做一处
任何一个镜头都能换候选、重新生成或手动替换。没改动的节点直接用缓存，不重复扣费。
数据在你自己电脑上
一个本地服务、一个 SQLite 文件、一个素材目录。平台密钥只存在本机，不进浏览器。
让 AI 替你点按钮
内置智能体「小满」能读画布、建节点、跑分镜；也可以交给本机的 Claude Code、Codex，或通过 MCP 从 Cursor 操作画布。

已接入 火山方舟、豆包语音、阿里云百炼、MiniMax，节点参数按所选模型自动给出。

开始使用

macOS 桌面版

适用于 Apple 芯片的 Mac。已签名并经 Apple 公证，自带 ffmpeg，会自动检查更新。

下载安装包

Docker 自部署

在自己的电脑或服务器上运行，打开 localhost:8787 使用。

git clone https://github.com/hoobnn/plein.git && cd plein && docker compose up -d

以 AGPL-3.0 开源。欢迎提 Issue，或参与开发新的模型平台和节点插件。
