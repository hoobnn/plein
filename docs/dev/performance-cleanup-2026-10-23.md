| 波形缓存         | `features/sequence/peaks.ts` 分开进行中的请求与成功结果；成功项按峰值数量做 LRU，预算为 1,000,000，空峰值至少计 1 个单位，超大单项返回后不缓存。保留并发去重及失败重试                             |

- 多父级创建：100 个已有 Frame 各追加 1 个子元素，从 10,000 次元素访问降为 100 次，`elements()` 调用 1 次、`children()` 调用 0 次；空批次及全新文档零扫描。混排、撤销重做、同批新容器、缺失/非容器父级、环下元素和只读行为均有回归。
- 卡片/便签：真实 Chromium 中直接驱动 50 次 Engine 预览，使用带分数尺寸的资产卡与文本卡；文档枚举为 0，全部边枚举等于绘线层的 50 次必要重画，覆盖层额外边枚举为 0。位置跟随、正文 DOM 复用、文档未被预览改写、改名后的引用失效及选中状态均检查。
- 分镜编号：真实 Doc/Scene 的 30 帧预览中不调用 `doc.elements()`，保留角标 DOM、移动和遮挡响应；语义变化后编号更新。
- 峰值缓存：10 项测试覆盖并发去重、HTTP/网络/JSON 失败重试、LRU 触达、多项淘汰、乱序完成、活跃引用、重访重载、超大项与空峰值。浏览器另验证请求失败可重试、30 分钟真实音频的 180,000 个峰值可显示和缩放。

相关单测/集成测试共 28 文件、243 项通过；全仓类型检查通过。相关 UI 回归 33/33 通过，另有隔离快照中的波形专项 2/2 通过。加强后的便签正文 DOM 复用与扫描计数用例在隔离快照中再次通过。独立审查发现并修复了 CSS 浮点序列化导致重复刷新，以及便签 DOM 断言只比较外层容器的证据缺口。

## 范围与限制

- 共享工作区的 `pnpm verify` 在并行 Agent 工作进行期间因其他文件的格式问题退出。本批文件的定向格式/lint 通过；完整复验使用 `HEAD 94bf794` 加显式清理路径的独立快照，复制现有锁定依赖，没有安装依赖或覆盖其他工作。
- 一次扫描仍包含 `effectiveParent` 的祖先链解析成本，不能声称任意深度的文档创建都严格线性。纯尺寸变化仍可能计算卡片内容。
- 峰值预算只限制共享成功缓存持有的数据。活跃组件、进行中的请求及其他页面资源不属于此预算；没有采集本轮长会话 heap、CPU trace 或 GPU 帧率，也不据操作计数推导 FPS 或总内存上限。
- 本轮使用临时数据和 mock Provider。没有重跑全部 E2E、远端 CI 或付费平台调用，没有提交或推送；临时快照和本轮无须保留的测试产物在完成后清理。
