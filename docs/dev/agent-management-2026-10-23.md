# 助手模型与上下文管理（2026-10-23）

## 产品行为

模型与推理强度放在助手输入框上方。模型选择作用于当前会话，不修改节点的默认生成模型。新会话按智能体记住选择，历史会话恢复自己的配置；失败保留原配置与草稿，保存期间阻止重复修改和发送。

内置目录仅包含已启用且支持工具调用的对话模型。Codex 懒加载本机 `model/list`，读取分页目录和每个型号支持的推理强度；错误不替换为虚构目录，手动重试绕过失败缓存。Claude 使用明确的稳定别名，具体版本及权限由 CLI 决定。

上下文检查区区分来源：内置助手报告预算裁剪后的请求估算；Codex、Claude 接收可识别的单请求输入用量。未知用量不猜数值，未知窗口不显示百分比。内置的 32,000 tokens 与 128 KiB 是 Plein 请求预算。模型变化或自动压缩使旧用量失效。

重置上下文保存单调的历史轮次边界，清除 CLI 恢复标识，保留展示记录、画布和执行回执。重启后不会把边界之前的展示记录作为 legacy 历史重新发送。CLI 移除指定模型覆盖时也建立新边界，确保“跟随 CLI 配置”不会继承旧的会话覆盖；界面提前说明，并在记录里留下通知。

运行中禁止更改配置及重置。模型目录查询期间，停止、删除、重置和其他配置请求可以使旧请求失效；迟到响应不能重新启动已取消的轮次或恢复已删除会话。前端还保护跨会话响应与同会话中较新的 SSE 状态。
