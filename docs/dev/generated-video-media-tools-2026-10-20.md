# 生成视频的媒体工具入口验收（2026-10-20）

## 结论

视频 crop 加工能力存在，但未锁定生成节点通过 `Generator → ResultActions(inline)` 展示结果操作，未渲染 `MediaTools`；导入素材和锁定节点走另一条浮动工具条路径。因此真实生成视频无法直接进入原生裁剪入口。

实现前只读子代理评审和实现后 diff 复审均通过。最小调整只有两个产品文件：

- `ResultActions` 为远程画布中的 inline 视频结果追加同一个 `MediaTools`，key 绑定节点和当前资产。
- `MediaTools` 增加可选 inline 按钮外观；默认仍为已有浮动工具条外观，取消按钮同步使用相同样式。

不改变主输出选择、采用、生成状态、只读门禁或派生资产流程；仍产出新视频素材，不修改已采用结果。不新增编辑器，不扩展图片或音频生成器入口。
