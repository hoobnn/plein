# 十分钟同画布持续操作验收

## 方法与范围

本轮固定使用 `90498a0` 产品构建的独立服务和完整 Chromium，启动时核对实际 Apple M4 Pro／Metal。固定夹具为 1000 个媒体、60 个节点、59 条连线，素材来自本地确定性图片／视频／音频，通过真实 API 上传，不调用生成模型。

同一个主引擎保持打开至少 600 秒，执行 20 个约 30 秒周期。每轮使用实际鼠标拖动一个媒体，点击撤销、重做、再次撤销并比较完整元素／连线快照；随后用真实滚轮平移与 Ctrl 滚轮缩放，核对视角变化且文档不变。测试入口只用于夹具、选定视图和观测，不用直接改坐标代替拖动或直接调用历史命令代替按钮。

周期交替包含打开／关闭检查点只读预览、移出全部媒体、局部查看以及返回全图。主引擎对象身份逐轮核对，不用快速重启浏览器替代持续使用。结束后重载页面，重新核对完整文档及 1000 个媒体就绪，构建入口哈希在会话前后必须一致。

仅在会话开始和结束各显式 GC 一次，过程中按浏览器自然 GC 运行，每轮记录堆、DOM、纹理和错误；不将堆或纹理计数直接解释为显存、物理输入延迟或屏幕帧率。

这是一轮十分钟自动化浏览器操作，不等同原生前台、实际 IME、物理触控板、多屏、休眠或数小时稳定性。安装版、制作数据及旧提交未知任务均未修改。

## 实际结果

本轮实际持续 600.005 秒，20 个周期全部通过，随后页面重载仍与原始完整文档一致，1000 个媒体预览就绪且失败为零。共 20 次拖动、40 次撤销、20 次重做、120 个平移滚轮事件和 20 次 Ctrl 滚轮；5 次检查点预览打开／关闭，没有意外替换主引擎。运行时、加载、卸载和 context 丢失警告均为零，构建入口哈希未变。

首尾显式 GC 后的 JS 堆分别为 48,272,096／64,585,892 字节，增加 16,313,796 字节。首尾 DOM 节点 14740／14753、监听器 4453／4460；过程中还加载了放大查看的图像变体、建立检查点数据和 GPU 几何。未做堆快照归因，不能将增长断言为泄漏，也不能宣称完全无泄漏。

本轮没有产品源码修改，不因单次持续会话通过重跑全仓或性能基准。详细逐轮记录见[原始报告](../benchmarks/2026-10-21-sustained-metal-session.json)，[结束画布](../benchmarks/2026-10-21-sustained-metal-end.png)保留显示状态；它们补齐本机持续操作和重载保留证据，不关闭原生物理输入、休眠或更长时间内存稳定性。

[综合结构化记录](../benchmarks/2026-10-21-sustained-native-acceptance.json)还保留了当前原生验收包的构建与启动范围、复现脚本和原始证据哈希。独立原生包内已实际检索到恢复事件注册、请求新帧及解除监听的代码；这项静态包核对仍不替代解锁后的前台验收。
