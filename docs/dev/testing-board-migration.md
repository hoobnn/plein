# 看板与分镜测试去向

本页记录原浏览器回归的替代位置，便于定位行为与维护测试。验证数字、失败注入结果和耗时记在对应提交中。

组件测试使用真实文档、store、API client 和组件，仅替换 HTTP、GPU 或解码边界。真实同步运输、布局命中、原生编辑、解码和下载字节由保留的 `@core` 验证。

路径约定：下表 spec 均在 `e2e/`；Board/Viewer/History 测试在 `apps/web/src/shell/`，分镜测试在 `apps/web/src/features/storyboard/`，ImpactPanel/impactPrices 在 `apps/web/src/features/runs/`，检查点和全景分别在 `apps/web/src/features/checkpoints/` 与 `apps/web/src/features/panorama/`。服务端测试使用明确的 `apps/server/src/` 路径。
