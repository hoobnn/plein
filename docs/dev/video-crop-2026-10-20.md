# 视频像素裁剪验收（2026-10-20）

## 结论和范围

真实制作中，视频主体可用但底部有色带。将已有 `crop` 扩展到视频能复用素材，避免付费重生成；只读子代理在实现前评审必要性、实现后复审 diff，均建议接受。

- 视频「媒体工具 → 裁剪」复用左、上、宽、高四个像素字段，按旋转元数据摆正后的画面计算坐标。
- 视频宽高必须为正偶数；左、上允许奇数，FFmpeg `crop=...:exact=1` 保留精确起点。图片仍允许奇数尺寸。
- 输出 H.264 / yuv420p MP4，沿用现有 libx264 / VideoToolbox 编码器选择，首条音轨转 AAC；无声源保持无声。不截时长、不改变速度。
- 沿用新资产、封面、来源参数及撤销机制，源文件不变。不扩展视频 rotate/flip、批量裁剪或可视化大编辑器。
- 服务端拒绝坏坐标、非法尺寸、越界、奇数宽高与不适用类型；缺 FFmpeg 时沿用能力隐藏与服务端错误路径。

## 接入条件

本变更保留在独立 checkout，避免主开发服务器热重载影响正在进行的生成任务。主会话确认全部真实任务已安全结束后，再将提交或补丁接入主工作树，并更新服务端和前端。无数据库迁移、无新增依赖。仅刷新浏览器不足以更新服务端能力。
