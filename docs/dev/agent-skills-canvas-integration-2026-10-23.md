# 技能管理与画布能力集成（2026-10-23）

## 实现范围

助手内选择技能与设置内管理技能使用同一个组件及服务端目录。支持搜索、来源筛选、指引详情、真实启停、启用并选用、能力元数据浏览。选择技能只写入本轮草稿，不自动发送；已有需求保留。技能元信息进入用户消息，原有审批、执行事实和撤销仍由同一会话链路处理。

首批 Plein 技能为检查画布、整理工作流、优化选中镜头、分镜规划与生成、素材加工。指引引用真实能力，并要求读取完整来源、检查实际输入、复用已有结果、在修改既有镜头时提出修改方案、不重发状态未知的任务。停用技能禁止该技能显式调用，不移除原有画布工具。

Plein 启停偏好按 owner 保存到数据目录的原子 JSON 文件，损坏或读取失败不会当作空配置覆盖。Codex 原生目录、刷新和启停通过本机 app-server；技能 ID 按来源路径生成，客户端不能指定任意文件路径。详情只读取目录返回的常规 `SKILL.md`，最多 64 KiB。Codex 开关真实修改本机配置，界面明确其作用范围；系统、管理员与未知来源不允许切换。Claude 仅显示 Plein 技能及原生能力仍由 CLI 管理的说明。

## 与画布的实际连接

输入框和历史消息展示真实目标名称、定位入口与删除状态。当前目标可逐个排除，整体排除仍保留。发送前复制目标 ID，并向工具及插件传递固定快照；未附带选区就是空目标，不会偷偷回退到其他客户端的实时选区。外部 MCP 在每次请求入口显式捕获选区，异步插件内复用该快照，下次请求可见新的选区。

新增能力均由同一注册表进入内置助手、CLI MCP、外部 MCP：

| 能力                 | 复用机制                             | 约束                                                                                   |
| -------------------- | ------------------------------------ | -------------------------------------------------------------------------------------- |
| `inspect_node_input` | `NodeRuns.preview` / `PreparedInput` | 只读；JSON Pointer 下钻；单页含格式化开销不超过 24 KiB；原文分页；实际输入变化拒绝续读 |
| `reorder_inputs`     | `@plein/doc` 的 `reorderInputs`      | 完整 edge ID 顺序；拒绝重复、缺项、跨端口或非多输入端口                                |
| `replace_input`      | `@plein/doc` 的 `replaceInput`       | 校验来源与目标端口；保留 edge ID、顺序及旧素材；拒绝重复引用                           |

顺序调整与槽位替换使用会话的 origin，真实按轮撤销测试验证可一次恢复原顺序与来源。能力目录展示实时元数据，技能不建立第二套节点执行或费用确认实现。

## 保留边界

本轮没有实现 Claude 原生 skill 扫描、远程技能安装、技能文件编辑或技能商城；也没有将展示技能目录等同于真实账户模型权限。批量分镜目前仍有 AI `run_storyboard` 与画布 `StoryboardBatches.preview/commit` 路径的差异，本轮不宣称它们的预检与复用行为已经统一；应在后续专门迁移批量调用合同，补齐输入变化与幂等提交验证。

验证使用本地 mock 平台、假 CLI 与受控浏览器响应，不调用真实付费模型或修改用户实际 Codex 技能配置。工作区其他清理、性能、桌面更新和生命周期改动保留。
