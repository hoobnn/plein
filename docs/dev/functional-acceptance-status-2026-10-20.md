# 画布功能验收总状态

目标保持为：每项操作能够正常工作、UI 正常展示、交互能让用户顺利完成任务。新增小回归通过不等于整体完成；不能以不断发现新边界替代完整用户路径验收。

## 推进方式修正

- 使用本文件汇总当前缺口；详细复现与定向结果仍归入 interaction-audit，不再仅靠追加日志判断整体进度。
- 优先关闭完整创作路径、组合回归、密集画布和真实生成的缺口。仅当新发现的问题会阻断路径、造成数据丢失、错误引用、误提交或明显不可操作时插入修复。
- 每个功能域同时核对操作、展示和交互。完整验收要检查正常操作、适用的失败恢复、取消／重复操作、状态持久化以及对应的视觉和输入反馈，不能只根据单测数量结案。
- 发布签名、公证和更新 feed 属于发布验证，不作为未完成当前画布功能验收的替代理由。跨机与外部工具验证单列；不取消已有明确用户要求，也不把本机模拟证据写成跨机或真实平台证据。
