# 3D 构图与动态预演

3D 构图用白模确定人物站位、姿态和机位。双击画布里的「3D 构图」节点可以打开编辑器；静态构图和原有截图仍然可用。

## 记录人物与镜头

1. 摆好起始人物、场景件和机位，点「启用动态预演」。起始状态会成为 0 秒关键帧。
2. 把「预演时间」移到另一个时刻，修改人物位置、朝向、姿态或镜头。修改会自动记录这一时刻，不覆盖其他关键帧；也可以点「记录当前关键帧」保留当前取景。
3. 点关键帧时间可跳回这一时刻；「删除当前关键帧」只删除所选时刻，至少保留一帧。时长为 1–60 秒，最多 60 帧；缩短时长前需先移除范围外的帧。
4. 点「播放预演」查看本机白模运动。人物位置、朝向和相机位置、看向点、焦距连续插值，朝向使用最短转角；姿态在关键帧处切换。人物名字、身高、颜色和场景件属于整个场景。

播放和拖动时间轴不修改场景、不增加撤销项，也不调用模型。播放中暂停编辑，暂停后可以继续。人物、镜头和关键帧修改沿用当前构图的撤销／重做；锁定节点或只读画布只能预览。

「保留当前静态构图」会将当前时刻的站位和镜头保留下来并移除轨迹，可以撤销。

## 截图与参考

暂停在要保留的时刻，点「截图」。截图成为不可变的图片候选，并保存完整轨迹、场景版本和截图时刻。之后编辑或播放不会改变已经保存的图片。

截图列表会显示时间。「恢复」恢复该截图对应的完整场景与轨迹，并将播放头移回截图时刻；采用截图只改变下游图片参考，不会恢复场景。截图编码／上传期间的编辑与采用选择仍然保留，迟到结果不会覆盖另一个节点或锁定节点。

目前提供白模预演与按时刻图片参考，不包含骨骼动画或预演视频导出。生成模型是否遵循白模空间安排，仍需实际生成后判断；本地预演不是生成效果验收。
