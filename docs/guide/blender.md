# Blender 构图交换

Plein 的 3D 构图可以导出供 Blender 编辑的场景文件。它与截图不同：导入后场景件、简化人偶和相机是 Blender 对象，可继续移动和编辑。

1. 在 Plein 打开 3D 构图，点击「Blender 插件」下载 `plein_blender_bridge.py`。
2. 在 Blender 的插件设置中通过「从磁盘安装」选择该文件，并启用 Plein 插件。
3. 回到 Plein，点击「导出到 Blender」保存 `.plein-stage.json` 文件。
4. 在 Blender 选择「文件 → 导入 → Plein 3D 构图」，打开导出的文件。

插件只读取所选本地 JSON，不启动网络服务。导入会新建一个集合，不删除已有对象；会将导入的相机设为当前场景相机，并设置画幅、24 fps 和预演帧范围。场景和相机包含可编辑的预演关键帧，导入时定位到 Plein 的当前预演时刻。

在 Blender 的 3D 视图按 N 打开侧栏，选择「Plein」，可以用「渲染图片供 Plein 导入」或「渲染视频供 Plein 导入」保存 PNG 或 MP4。渲染使用当前场景的相机、渲染引擎和帧范围；插件会恢复原有输出设置。也可以使用 Blender 自己的渲染功能。

回到 Plein 的 3D 构图，点击「导入 Blender 渲染」选择文件。素材会作为独立图片或视频节点放到构图节点旁，不会覆盖构图截图或伪造截图来源；导入后画布会定位到新素材。回传需要手动选择文件，不会自动跨应用同步。

场景数据目前只从 Plein 导入 Blender，Blender 的任意模型、材质或修改不能直接回写 Plein。人偶和材质是简化近似，姿态与动画插值不保证逐帧一致；坐标、机位、焦距与基础尺寸按 Plein 构图转换。
