# 角色档案

资产库里的角色按用途管理图片，并保留名字、基础设定、标签、基础音色和**档案**。打开角色时，默认进入「角色资产」，先看同一个人的四类基础图片：

| 图片         | 用途                                                               |
| ------------ | ------------------------------------------------------------------ |
| 全身定妆图   | 固定体型、服装和整体造型；默认用作角色封面和生成时的第一张基础参考 |
| 肖像／半身图 | 固定脸部、发型和上半身细节                                         |
| 情绪九宫格   | 汇总同一人物的多种表情，方便对照表演和情绪                         |
| 角色设定图   | 正、侧、背等角度的三视图或设定板，固定造型细节                     |

四类图片集中展示，可以预览、上传、替换、移除，也可以从当前画布选图。预览保留完整画面，竖向全身图和横向设定板都不会被裁掉。草图、来源图及暂未归类的图片放在「其他参考」，之后可以重新分类。保存后，再次打开仍会保留分类。

四类图片与其他参考合计最多 24 张。达到上限后，可以把已有的其他参考归入四类，或替换已有图片。图片上传时，等待上传完成再保存或添加到画布。

旧角色里的「全身主图」「半身图」「情绪九宫格」「设定图」会对应到这四类，原有图片和其他参考继续保留，无需重新上传。替换或移除只改变角色与该图片的关联；画布上已有的素材和本机图片文件会保留。

角色名称在编辑页顶部修改。「基础设定」分页管理外貌描述、标签和基础音色；「时期与服饰」「表情」分页管理角色的变化。档案以「时期」为主线，把同一个角色在不同年龄、造型和情绪下的样子分开记下来：

| 部分     | 内容                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 时期     | 童年、少年、青年……每个时期有一段样貌设定、最多 4 张参考图和一个主音色                  |
| 状态音色 | 挂在时期下：生病、醉酒、耳语等状态下换用的次音色                                       |
| 服饰     | 挂在时期下：这一时期的多套造型，每套有一段描述和最多 4 张参考图                        |
| 表情     | 跨时期通用：开心、愤怒……每种有一段描述和参考图；总览用的「情绪九宫格」在角色资产里管理 |

编辑页的「时期与服饰」分页一行一个时期，按先后从上往下排，右边是这个时期的服饰：点时期改样貌和音色，点服饰改这一套，也可以在「属于时期」里把它挪到别的时期名下。资产库列表里，角色卡片底部按时期写出服饰套数（如「少年 3 套 · 青年 2 套」），悬停时按时期列出各自的服饰小图。

时期、服饰、表情都带常用预设，可一键添加。同一个角色里不能有重名；改名后旧名字会被记住，使用旧名的提示词仍然有效。

档案条目名称重名或含有不允许的符号时，保存及“保存并添加到画布”会暂停，并定位到错误字段。修正后可继续保存。

新增条目的名字已被使用时，会自动寻找空闲序号，也会避开旧名。长名字会为序号留出长度，保留完整的表情与组合字符。

## 从图片槽位开始制作

在角色资产页，可以从全身定妆图、肖像／半身图、情绪九宫格或角色设定图的制作入口开始。Plein 先保存当前角色，再把现有设定和参考放入独立的图片草稿；三视图、表情九宫格使用相应提示词配方。创建草稿不调用生成平台，需要在画布中核对参考、选择模型并手动生成。

采用满意的图片候选后，使用“归档到角色”，核对原角色、制作时的图片类别以及本次实际归档的槽位。可以明确改选槽位，也可以设为资产库封面。封面单独保存，不会把肖像改标成全身图，也不改变模型参考图的优先顺序。

归档绑定角色 ID 和具体采用候选，不按同名角色猜测目标。新图替换槽位后，旧图转为“其他参考”保留；已在角色里的同一张图移入所选槽位，避免重复占用容量。保留旧图后超过 24 张时，先清理不需要的参考再重新核对。原角色的项目归属、设定、音色与档案保持原值，画布上的角色副本仍由既有同步入口明确更新。

角色、候选、图片或编辑权限变化后，旧确认不能直接归档。发生版本冲突时重新读取并核对，不自动用旧快照覆盖新内容。示例角色起点只提供可编辑的设定，尚未生成图片；选择示例也不会自动运行模型。

## 在提示词里引用

写 `@林夏/少年/校服/开心` 即可指定角色的时期、服饰和表情。`/` 后面的部分顺序随意，每类最多写一个；只写了服饰或状态音色时，时期自动取它所属的那一个。输入 `@林夏/` 时，会弹出档案里还没写到的那几类供选择。

运行时：

- 设定按「基础设定 → 时期 → 服饰 → 表情」依次叠加进提示词，后面的覆盖前面的；
- 参考图先放命中项的图（时期、服饰各两张，表情一张），再补卡片本身的参考图，每个角色最多 6 张；基础参考按「全身定妆图 → 肖像／半身图 → 角色设定图 → 情绪九宫格 → 其他参考」排序；
- 配音的音色按「状态音色 → 时期主音色 → 基础音色」取第一个设置了的，并且仍然只在同一家平台内沿用；
- 写了档案里没有的名字时，这一段按普通文字处理，并给出提示。

## 画布上的角色卡

把角色从资产库放到画布上，四类基础图片和其他参考会按上述顺序作为素材连入角色卡；没有图片的类别会跳过。角色卡会带上一份档案副本，卡片上显示时期、服饰和表情各有多少。档案统一在资产库里编辑（生成器里点「编辑档案」），保存后，打开“查看画布中的版本”，比较差异并选择要同步的画布和字段；可以固定某张卡片的旧版本。

跨项目列表会显示来源项目，未归属条目单独标注；项目同名时附短标记区分。来源名称读取失败时可重试，资产仍可浏览。编辑其他项目的条目时，勾选“保留在来源项目”会维持原归属，取消后成为未归属条目。保存尚未返回时重新勾选，会保留草稿选中的来源项目；解除归属保存完成后再勾选“归到当前项目”，则归到当前项目。
