# 角色档案

资产库里的角色除了名字、基础设定、参考图槽位、标签和基础音色，还有一份**档案**，以「时期」为主线：

| 部分     | 内容                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 时期     | 童年、少年、青年……每个时期一段样貌设定、最多 4 张参考图、一个主音色        |
| 状态音色 | 挂在时期下：生病、醉酒、耳语等状态换用的次音色                             |
| 服饰     | 挂在时期下：这一时期的多套造型，各自一段描述和最多 4 张参考图              |
| 表情     | 跨时期通用：开心、愤怒……各自一段描述和参考图；「情绪九宫格」作为总览放在这 |

时期、服饰、表情都带常用预设，点一下就能加。同一个角色里名字不能重复；改名后旧名记下来，旧提示词照样能用。

## 在提示词里引用

写 `@林夏/少年/校服/开心`，`/` 后面的部分顺序随意，每类最多一个；只写服饰或状态音色时，时期取它所属的那一个。输入 `@林夏/` 会弹出档案里还没写的那几类。

运行时：

- 设定按「基础设定 → 时期 → 服饰 → 表情」叠加进提示词，后面的覆盖前面的；
- 参考图先放命中项的图（时期、服饰各两张，表情一张），再补卡片的参考图，每个角色最多 6 张；
- 配音用的音色按「状态音色 → 时期主音色 → 基础音色」取第一个有的，仍然只在同一家平台内沿用；
- 写了档案里没有的名字时，这一段按普通文字处理并给出提示。

## 画布上的角色卡

从资产库放到画布上的角色卡带着档案的副本，卡片上显示各时期和服饰、表情的数量。档案在资产库里编辑（生成器里点「编辑档案」），保存后当前画布上的这张卡自动同步。
