# 全景浏览与场景视角

在资产库编辑场景，把 **2:1 等距柱状全景图**放入“全景”槽位，再点击“浏览全景与截取视角”。入口先保存当前场景并读取最新版本；画布上的旧场景卡保留原内容。

拖动预览可以转动朝向和俯仰，滚轮调整垂直视角。也可以填写角度，或在预览上使用方向键与 `+` / `−`。朝向 0° 对应全景图的水平中心，正朝向向右转，正俯仰向上看。预览按球面经纬度投影成透视画面。

选定画幅后，为镜头填写明确的视角名和描述，点击“保存为命名视角”。Plein 在本机服务中从原图重新投影，生成新的 PNG，并追加到该场景的视角档案：

| 画幅      | 截图尺寸  |
| --------- | --------- |
| 横屏 16:9 | 1024×576  |
| 竖屏 9:16 | 576×1024  |
| 方形 1:1  | 1024×1024 |

视角名沿用场景档案的规则：1–20 字，不能含空格或 `/`、`@`、`#`，也不能与其他视角或旧名重复。每个场景最多保存 24 个视角。

通过“查看画布中的版本”明确同步场景视角后，可写 `@场景名/视角名` 引用。实际输入只使用该视角的截图；原全景作为截取来源单独保留，不自动补入模型参考图。普通编辑、检查点和项目包会保留截图及原图来源。

源图支持 PNG、JPEG、WebP 和 AVIF，上限为 3200 万像素、64 MiB。处理时原图最多解码到 4096×2048，截图最多为 1024×1024；这些限制不会改写原文件。此入口只做本地浏览和投影，不调用生成平台。

读取或保存期间场景、原图或权限发生变化时，旧确认会停止。关闭后重新打开全景，读取最新场景并再次核对。只读状态仍可检查已有内容，不能保存新视角；等待截图时可以取消。
