# 视频局部加工与识别分句切分

选中画布上的单段视频，在「媒体工具」的本地处理区进入高级加工。生成的都是新视频，保留源文件；这些操作不提交生成模型。

## 区域修补

「区域修补（本地插值）」用矩形周围的背景填补画面区域。输入摆正后的像素坐标与尺寸，可以在预览中核对位置，再指定生效的入点和出点。矩形四周至少保留 1 像素背景。

它适合固定位置、简单背景的标记或文字区域，复杂纹理可能模糊；不会识别或跟踪字幕。原音轨与视频时长保留。本机缺少区域插值滤镜时，入口会显示不可用原因。

## 片段替换

把另一段视频放到当前画布，进入「片段替换」，选择具体素材、原视频的入点／出点，以及替换素材起点。替换画面会按原画幅等比缩放并补边，其他时间段的画面和原视频音轨保留，不引入替换素材声音。

原视频需要固定帧率，入点和出点须对应真实帧边界；未对齐时会提示可填写的秒数。替换素材必须有足够的等长片段，不会静默补帧或拉伸。校验失败时保留填写，可以修改后重试。

确认绑定当前的具体文件与画布元素。等待期间换采用项、删除／重建素材、锁定或切换只读状态，旧确认会失效。取消仅中断本次加工。产物的加工来源随画布、撤销、检查点和项目包保存，源视频及替换素材仍作为明确引用保留。

片段替换使用已有视频素材合成；按提示词生成局部画面的原生视频编辑仍需要相应模型接口。

## 根据语音识别结果准备切分

选中单段音频，在「媒体工具 → 手动切分」中，可以创建语音识别草稿。核对模型后手动识别，再回到原音频的切分表单。

「按语音分句准备区间」会核验已采用识别结果的真实作业输入，只列出确实识别过当前音频的结果。重连识别节点不会改变旧结果的来源；等待期间换音频或采用项，旧读取不能用于新素材。

使用识别区间后会切换到可编辑的「自定义区间」，保留原始精度、顺序和空白。确认前检查所有区间，随后才会执行本地切分。实际切分支持 2–20 段；不足或超过限制的完整识别计划会提示先编辑，不自动丢弃分句。异常、重叠或乱序时间戳不能直接导入。

识别可能按所选平台计费，创建草稿和导入已有结果不会自动调用识别模型。这是语音时间戳到切分计划的接续，不包含节拍检测或人声分离。
