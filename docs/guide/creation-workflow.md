# 从分镜样片到交付

## 按下一步继续创作

包含分镜表的画布在顶部提供“创作下一步”入口。空间足够时，引导在右侧展开，并给节点和生成器预留空间；空间不足或已打开任务／助手面板时，点击顶部入口，在独立窗口中查看。它显示梗概、分镜、试做一镜、审核样片、批量和交付的进展，选择步骤只定位或打开对应编辑器，不会自动调用生成平台。可以跳步、收起，也可以继续自由操作画布。

多个分镜表或成片序列需要明确选择。分镜计划的“已人工核对”是本机记录，计划改变后失效；生成成功不会自动获得创作验收结论。离线时可以查看和定位，生成与导出仍需要连接服务。

同名分镜和成片会显示短 ID 供区分。已选内容删除或不再关联后，即使只剩一个候选，也需要重新选择；不会自动换到另一条创作线。定位目标或待核对计划变化时，引导会说明原因，核对更新后可重试。

已选试做镜头移除后会保持待检查，撤销恢复或重新选择后继续；不会自动改用第一镜。镜头展开后，交付入口按当前有效视频、对白和音效连线识别成片，仅接入配乐的声音不计为该镜头的成片关联。

## 先看节奏样片

在分镜表点击“节奏样片”，或在引导中打开低成本分镜样片。首次会创建独立的“样片草稿”节点，快照当前采用的分镜图和已经生成的配音；不会沿上游调用图片、视频、配音或字幕识别。

样片可以调整镜头顺序、时长、对白延迟、句间停顿和字幕，在浏览器预览或本地导出 MP4。缺图时明确占位；导出带 `DRAFT` 标记。它用于检查叙事和节奏，不能代表视频动作或最终生成质量。

字幕样式加载期间会暂用近似样式，保证预览仍能读到对白；加载失败时可点击“重试字幕预览”，无需关闭窗口。近似样式只影响浏览器预览，导出仍按服务端字幕样式合成。

逐句字幕的空文本和无效时间会在对应字段旁提示原因；修正内容或关闭该句显示后可继续导出。切换字段、点击按钮和切换显示开关会分开记录撤销步骤；输入框内保留原生文本撤销，在预览按钮等位置使用撤销快捷键可撤销文档修改。

更换分镜图或配音后，点“更新样片素材”重新取快照；已有镜头的节奏设置和旧样片候选保留。样片与视频成片使用不同节点，可以切换到关联的成片序列继续制作。

只读画布仍可打开已有样片查看；创建新样片受限时会说明原因，恢复可写后可以重试。

## 记录镜头是否可用

“审核镜头”与候选全屏预览提供独立的“创作验收”。可以标记“待审／可用／需修改”，选择角色、构图、动作、声音、衔接等问题标签并写备注。审核不改变当前采用项；预览其他候选时先明确采用，再记录该候选的验收。

结论绑定具体候选。换候选后重新待审，旧记录保留；输入改变时提醒核对旧候选。审核表可按状态筛选，或跳到下一待审镜头。清空音效、删除台词只保留历史，不会继续成为当前计划的审核和批量生成项。

## 审阅批量生成清单

分镜表的批量按钮先打开清单，列出本次生成、沿用、阻塞和跳过的项目，以及各自原因。镜头引用的资产准备也在清单里。默认补齐未完成项；选定镜头或使用“全部重新生成”时创建新候选，旧候选保留。

预检不会提交模型。可以展开看实际输入，定位阻塞项修复，再重新检查。内容或任务变化后旧确认失效；确认排队后输入再次变化，也会在执行前转为重新审查。原任务提交未知或等待取回时，应去恢复原任务。

调用次数是本次任务的预计模型调用，不包含自动重试，也不等于实际扣费。配置过单次价格时显示估算，未配置则明确显示价格未知。必需参考没有可运行的准备来源时不会先为无用的准备项生成。

## 比较相邻镜头

在逐镜审核中打开连续性审看。上一镜尾帧与当前镜首帧来自真实素材抽帧，可以固定角色参考，并循环播放剪切点前后各一秒，短于一秒的素材使用整段。

这是辅助人工检查服饰、光线、朝向和动作衔接的视图，不自动判定连续性，也不生成新镜头。意见继续记录到当前候选的创作验收中。

## 回看实际 MP4 并确认交付

样片或成片导出成功后，进入“实际 MP4 回看 / 交付”。播放器读取已经入库的导出文件；它与编辑时的预览分开。每个导出结果都有独立版本、规格、时长和意见。

暂停在需要修改的时间，添加时间码意见；有来源映射时可以定位到镜头返工。解决全部意见后，可以人工确认这个版本可交付。再次导出建立新记录，不继承旧版的确认；给已确认版本补充意见后也需要重新确认。

切到剪辑预览再返回，会保留当前审阅版本、各版未提交意见和播放位置；离开时停止播放，返回后保持暂停。同一版本的实际视频被替换时，会提示重新核对，并从新文件开头开始。未提交草稿只在本次打开序列窗口期间保留，关闭窗口或刷新后清空；需要长期保存的意见请先添加到对应版本。

审核、时间码意见与交付记录不会改变生成参数或触发重跑，随文档、命名检查点和项目包保留。已删除或改绑的来源不会被历史意见误认作新的镜头；无法定位时仍保留原版本和镜头身份供核对。
