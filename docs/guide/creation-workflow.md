# 从分镜样片到交付

## 画布鼠标操作

左键点击选中元素；按住左键移动达到约 3 个屏幕像素后拖动元素，轻微抖动不会移动元素。按住鼠标右键拖动可平移整张画布，不改变元素位置或选区；右键轻点仍打开快捷菜单。中键拖动、空格加左键拖动和抓手工具也可移动画布。

## 卡片下方的节点编辑器

选中一个节点后，编辑器始终固定在对应卡片下方。它随卡片一起平移、缩放定位，不再根据边缘剩余空间压缩尺寸、翻到上方或自动收起，也不会停靠到窗口侧边。顶部集中显示上传、画布参考、创作配方和参考缩略图，中间编辑提示词，底部单行排列模型、模式、参数和生成操作。画布参考可以搜索并接入已有素材。内容较长时在编辑区内滚动，底栏保持可见；右上角关闭按钮可取消选中。

顶部参考素材以服务端准备的实际输入为准，包含连线图片、`@` 引用自动带入的图片和续镜接续帧。缩略图、实际输入预览和多模态 `@imageN` 共用顺序；视频、音频各自编号。未送入的连线素材单独折叠显示，不占实际编号。提交时校验这份输入，输入变化后先刷新给用户查看。

引用角色后，可在顶部“角色参考”选择自动附图、指定某一张或仅文字。选择只作用于当前节点，按图片资产 ID 保存；角色图片重排不会换图，已选图片失效时要求重新选择。“仅文字”控制 `@` 引用的自动附图，已手动连入的图片仍按连线使用。

续镜保存的接续帧固定为图片 1；历史连线丢失时仍补齐该帧并去重。前镜视频更新后，旧接续帧会阻断生成，需要先点击“换成新画面”；缺少连线时也可更新保存的接续帧。

## 逐镜头制作流程

打开分镜节点的“分镜表”后，可在镜头表格中按行编辑时长、画面、景别、光影、对白、音效和运镜。运镜支持预设与自定义描述，只合入视频提示词；不指定运镜时保持原描述。需要编辑角色绑定、镜头状态或完整生成设置时，切换“详细卡片”；视图偏好保存在本机。

顶部流程可以随时切换：确认镜头、准备资产、合成提示词。资产阶段按本分镜实际引用的角色、场景和道具显示素材，计数仅表示已有可取得的参考图，不表示已人工验收；未绑定或缺图的素材单独标出，打开对应素材节点可继续准备。

“本地补齐提示词”按镜头画面、绑定资产、声音、运镜和全局视觉风格拼接，只补空白字段，已有提示词保持原文。选择镜头时只补所选范围。更改视觉风格后，已有提示词需要逐镜核对或重新拼接。“查看提示词”分开编辑分镜图与视频运动提示词，失焦或关闭时保存，可撤销。

合成提示词不调用生成平台。阶段末尾可展开镜头节点，再通过原有视频生成清单检查实际输入并决定执行范围；编辑表格不会自动覆盖已展开节点，需要在计划差异中确认同步。工具栏保留当前主操作，其余展开、批量、差异、审核、原文和样片入口收在“更多分镜操作”中。

## 按下一步继续创作

包含分镜表的画布在顶部提供“创作下一步”入口。空间足够时，引导在右侧展开，并给节点和生成器预留空间；空间不足或已打开任务／助手面板时，点击顶部入口，在独立窗口中查看。它显示梗概、分镜、试做一镜、审核样片、批量和交付的进展，选择步骤只定位或打开对应编辑器，不会自动调用生成平台。可以跳步、收起，也可以继续自由操作画布。

多个分镜表或成片序列需要明确选择。分镜表的查看选择、引导收起状态保存在本机；试做镜头和交付序列的明确选择随文档同步。旧版保存在本机的试做／序列选择仅作查看 fallback；之后在当前分镜上的明确选择优先使用文档记录。旧本机 `reviewedPlans` 不作为有效人工确认，也不自动迁移。

“我已人工核对这份分镜”记录当前画布、稳定分镜身份、完整分镜内容、版本标签、界面操作人和时间。修改内容后重新待审，原记录保留在“分镜核对历史”中；恢复原内容可重新显示同一范围的原核对。其他分镜、删除后同名新建、复制、模板或项目包导入、检查点恢复不能继承当前范围的确认；副本仅保留有出处的历史，需重新核对。检查点恢复建立新画布；项目包导入即使保留原身份，也将原确认显示为历史，需重新核对。

“制作决策”可记录模型、风格等选择和修订理由，每次保存新增一条修订，旧条目保留。当前选择按同一范围、类型与对象的最新记录显示；保存记录不会修改模型、生成参数或调用平台。代表镜头是否可用，继续使用该镜头具体候选的创作验收。

内容核对、生成执行授权、候选采用和交付确认分别记录。核对或复制历史不会携带审批 token、续发任务或授权生成；生成成功不会自动获得创作验收结论。只读画布可查看记录，不能保存核对、决策或文档选择。每次保存与选择可单独撤销、重做；撤销当前追加会从可见历史移除此条，重做恢复同一记录身份，其他客户端的条目保留。这是协作文档的来源记录，不是不可更改的审计账本。离线时可以查看和定位，生成与导出仍需要连接服务。

同名分镜和成片会显示短 ID 供区分。已选内容删除或不再关联后，即使只剩一个候选，也需要重新选择；不会自动换到另一条创作线。定位目标或待核对计划变化时，引导会说明原因，核对更新后可重试。

已选试做镜头移除后会保持待检查，撤销恢复或重新选择后继续；不会自动改用第一镜。镜头展开后，交付入口按当前有效视频、对白和音效连线识别成片，仅接入配乐的声音不计为该镜头的成片关联。

分镜数据出现异常时，编辑器会列出原始行号与无效字段，暂停编辑和批量操作，不会把坏行静默删除。可逐行恢复无效字段并撤销；台词等列表需要整体重置时会先说明影响。重复或空镜头标识的恢复会分配新标识，已有素材保持原关联，恢复后需重新核对或展开。镜头列表本身损坏时可显式重置为空列表，原始数据仍能通过撤销恢复；只读画布不能执行恢复。

## 先看节奏样片

在分镜表的“更多分镜操作”中点击“节奏样片”，或在引导中打开低成本分镜样片。首次会创建独立的“样片草稿”节点，快照当前采用的分镜图和已经生成的配音；不会沿上游调用图片、视频、配音或字幕识别。

样片可以调整镜头顺序、时长、对白延迟、句间停顿和字幕，在浏览器预览或本地导出 MP4。缺图时明确占位；导出带 `DRAFT` 标记。它用于检查叙事和节奏，不能代表视频动作或最终生成质量。

字幕样式加载期间会暂用近似样式，保证预览仍能读到对白；加载失败时可点击“重试字幕预览”，无需关闭窗口。近似样式只影响浏览器预览，导出仍按服务端字幕样式合成。

素材时长或尺寸读取失败时，会提示预览排布可能不完整，可点击“重试素材信息”或顶部“重新加载预览”重试。重新加载也会刷新画面、缩略图及波形，保留剪辑设置和播放位置。成功读取的信息复用缓存；更换素材后按新素材读取，不沿用旧错误。

镜头采用的实际素材变化时，尚未提交的入出点草稿失效，已保存的剪辑设置保留；字幕草稿可以继续编辑。入点必须早于有效出点及实际素材结尾。已保存出点超出新素材长度时，预览和导出按素材结尾计算。

点击时间刻度、拖动播放头、重排或修剪镜头，以及使用“铺满”后，可直接按 Home／End 跳到开头／结尾，方向键逐帧移动，空格播放或暂停。焦点仍在缩放滑杆时，这些定位按键先用于调整缩放；点击刻度后交回时间线。

Tab 聚焦镜头卡片时只切换右侧镜头设置；按回车或空格激活该卡片，会暂停并定位到对应镜头开头。卡片的空格用于定位，时间线本身的空格用于播放或暂停。只读画布仍可使用这些预览操作，剪辑设置不会改变。

视频时长尚未读到时，时间线先显示临时占位，避免镜头卡片挤在一起。本镜头或前序镜头缺少有效时长时，可选择查看设置，暂不能按镜头定位、重排或拖边修剪；信息就绪后需再次操作，不自动执行之前的激活。读取失败可重新加载预览。重名镜头的辅助说明包含序号和总数，便于区分。

拖动重排或修剪时，如果镜头顺序、采用素材或已保存的剪辑布局发生变化，本次拖动会取消并提示重新操作，卡片立即落在新位置。仅字幕、混音等无关字段更新时可以继续；提交时保留最新设置。取消后可按当前内容重新拖动，新操作仍可撤销重做。拖动期间缩放时间线、改变窗口宽度或横向滚动，也会取消本次操作，避免用旧坐标保存修剪或顺序；缩放没有实际变化时可以继续。修剪预览更新画面和播放头时保持视图位置，避免手柄随自动跟随滚动而跳走；开始重排时暂停播放。

逐句字幕的空文本和无效时间会在对应字段旁提示原因；修正内容或关闭该句显示后可继续导出。切换字段、点击按钮和切换显示开关会分开记录撤销步骤；输入框内保留原生文本撤销，在预览按钮等位置使用撤销快捷键可撤销文档修改。

只读画布仍可打开已有序列、定位、播放和缩放时间线；参数编辑、镜头排序、修剪和生成新成片会停用，并显示只读说明。修剪期间变为只读会取消未提交的草稿。

更换分镜图或配音后，点“更新已有素材”重新取快照；已有镜头的顺序、节奏设置和旧样片候选保留。分镜新增的镜头按分镜顺序追加到样片末尾，已从分镜删除的镜头会从样片中移除；刷新可撤销。样片与视频成片使用不同节点，可以切换到关联的成片序列继续制作。

来源分镜或已采用素材的记录无效时，创建和刷新会显示原因；刷新失败会保留原样片、镜头顺序和节奏。已有样片仍可打开查看，修正来源分镜或重新采用有效素材后可重试，不会自动调用生成平台。

只读画布仍可打开已有样片查看；创建新样片受限时会说明原因，恢复可写后可以重试。

本地成片导出失败时，编辑器会显示失败提示，展开“查看错误详情”可阅读和选取完整原因；已有成片及交付记录保留。修正素材或导出设置后可重新导出。更换样片采用的分镜图或配音后，先点“更新已有素材”更新快照，再重新导出。

“导出工程”会先读取 ZIP 文件并检查文件类型及归档头尾，再交给浏览器保存；提示“已交给浏览器下载”后，请查看浏览器保存状态。读取过程中可取消，失败后可重试；关闭编辑器或修改剪辑内容会取消本次读取，避免下载旧版本。工程包含素材，较大文件需要更多读取时间及浏览器资源。导出会先等待镜头及对白的有效时长，期间显示读取提示并允许取消；信息读取失败或缺少有效时长时会说明原因，避免按临时时长排布而漏掉后续对白。

## 记录镜头是否可用

“更多分镜操作 → 审核镜头”与候选全屏预览提供独立的“创作验收”。可以标记“待审／可用／需修改”，选择角色、构图、动作、声音、衔接等问题标签并写备注。审核不改变当前采用项；预览其他候选时先明确采用，再记录该候选的验收。

结论绑定具体候选。换候选后重新待审，旧记录保留；输入改变时提醒核对旧候选。审核表可按状态筛选，或跳到下一待审镜头。清空音效、删除台词只保留历史，不会继续成为当前计划的审核和批量生成项。

## 审阅批量生成清单

分镜表的批量按钮先打开清单；已展开时“批量出分镜图”是主操作，其余批量入口在“更多分镜操作”中。清单列出本次生成、沿用、阻塞和跳过的项目，以及各自原因。镜头引用的资产准备也在清单里。默认补齐未完成项；选定镜头或使用“全部重新生成”时创建新候选，旧候选保留。

预检不会提交模型。可以展开看实际输入，定位阻塞项修复，再重新检查。内容或任务变化后旧确认失效；确认排队后输入再次变化，也会在执行前转为重新审查。原任务提交未知或等待取回时，应去恢复原任务。

调用次数是本次任务的预计模型调用，不包含自动重试，也不等于实际扣费。配置过单次价格时显示估算，未配置则明确显示价格未知。必需参考没有可运行的准备来源时不会先为无用的准备项生成。

## 比较相邻镜头

在逐镜审核中打开连续性审看。上一镜尾帧与当前镜首帧来自真实素材抽帧，可以固定角色参考，并循环播放剪切点前后各一秒，短于一秒的素材使用整段。

这是辅助人工检查服饰、光线、朝向和动作衔接的视图，不自动判定连续性，也不生成新镜头。意见继续记录到当前候选的创作验收中。

## 回看实际 MP4 并确认交付

样片或成片导出成功后，进入“实际 MP4 回看 / 交付”。播放器读取已经入库的导出文件；它与编辑时的预览分开。每个导出结果都有独立版本、规格、时长和意见。

暂停在需要修改的时间，添加时间码意见；有来源映射时可以定位到镜头返工。解决全部意见后，可以人工确认这个版本可交付。再次导出建立新记录，不继承旧版的确认；给已确认版本补充意见后也需要重新确认。

切到剪辑预览再返回，会保留当前审阅版本、各版未提交意见和播放位置；离开时停止播放，返回后保持暂停。同一版本的实际视频被替换时，会提示重新核对，并从新文件开头开始。未提交草稿只在本次打开序列窗口期间保留，关闭窗口或刷新后清空；需要长期保存的意见请先添加到对应版本。

审核、时间码意见与交付记录不会改变生成参数或触发重跑，随文档、命名检查点和项目包保留。已删除或改绑的来源不会被历史意见误认作新的镜头；无法定位时仍保留原版本和镜头身份供核对。

## 在剪辑中返工一个片段

在序列编辑器选中镜头后，使用“剪辑内返工”的“修改并生成候选”。Plein 将来源节点当前的输入复制为独立返工草稿，在窗口内修改提示词、参考和参数，再手动生成。这里生成的是整段视频候选，使用来源节点现在的输入，不保证还原旧候选当时的输入。

原片段与新候选可分别播放比较。选择具体候选后，点击“仅替换此剪辑实例”才写入剪辑；生成完成本身不会替换原片段。旧版自动声音关系首次固定时，需要明确选择原生声音、独立配音或混合。其他实例和来源节点的采用项保留。

替换会保留该实例的入出点、速度、对白、音效及字幕设置，并提示重新核对；旧字幕可能过期，需要重建或重新识别。候选短于保留的修剪范围时先调整范围，再重新操作；实例、候选或编辑权限在核对期间变化时，不会应用旧选择。

关闭返工窗口保留草稿、候选与任务，可以回画布定位草稿继续处理。导入视频、来源已删除或无法确认本画布来源时，不猜测生成出处；可以先创建视频生成节点，再使用已有的固定素材替换操作。

## 将一段素材用于多个镜头

在序列中明确选择一个视频候选和输出端口，将它固定为素材。可以选历史候选，固定操作不改变原节点的采用项。固定素材绑定具体文件；原节点之后采用其他候选，不会替换已经固定的素材。导入的视频没有生成任务出处时，界面保留未知，不按相同文件猜测任务。

“原始生成出处”只显示已有证据的原任务；复制或导入候选不会把新画布、节点或本地任务别名当成原任务。“选取位置”单独保存当时固定的本地候选。旧候选缺少原任务证据时仍可查看与固定，原始出处保持未知。

同一份固定素材可以添加或复制为多个剪辑实例，分别选择叙事分镜和镜头，再独立修剪、变速、重排和修改字幕。选中或删除一个实例不会修改另一个实例；原生成节点或素材卡片删除后，已保存的固定实例仍引用原文件。替换文件是对选中实例的明确操作，已有字幕与设置会提示重新核对；文件缺失或入出点越界时先修复，不自动调用生成平台补回。

新增共享实例需要明确选择声音：“原生声”只用视频自带声音，“独立配音”关闭该实例原声，“混合”才同时使用两者。新增或复制实例不会自动顺序认领已有对白或音效；需要时明确绑定。已有序列的自动声音关系保持原方式。视频变速会调整原声的播放速度并保持音高，独立配音仍按成片时间播放。

字幕跟随具体实例；复制后拥有独立条目，编辑其中一句不改其他实例。旧手工轨的文字、时间和隐藏状态保留，旧版同源多端口已经重复显示的字幕也不会在升级时偷偷去重。素材、速度或相关输入改变时，旧轨继续提示过期，不能直接沿用旧键当作重新识别。重排和删除只有在原轨及其实际输入仍有效时才保留相对字幕时间。

旧字幕无法对应到当前实例时，“未映射旧字幕”保留原值和原因供核对，不猜着把它放进成片；修改当前字幕也不会抹掉这份旧记录。

批量清单按选定序列核对共享映射：已有固定素材的叙事镜头沿用该文件，即使没有独立的视频生成节点，也不重复补生成。存在多个不同剪辑方案时先选择序列；固定共享源的明确重拍会列出实际使用者并要求先解除所选绑定或建立独立来源，不悄悄影响其他镜头。

实际 MP4 的重叠区间可以对应多个来源。交付回看会同时显示各剪辑实例、源文件时间和速度，意见可绑定具体实例并定位回剪辑。MP4、字幕和工程使用同一时间线；工程 ZIP 的 `clip-map.json` 另存完整来源与时间转换，OTIO 也携带相关元数据。剪辑软件是否应用私有信息仍需导入后核对。

复制、模板、检查点和项目包保留固定文件与剪辑设置。副本分配独立实例身份并映射明确的内部叙事引用，原生成出处和旧交付记录保持历史；项目包导入即使保留原画布 ID，也不会因此继承新范围的人工核对、验收或执行授权。只读或锁定状态可以查看与定位，不能保存剪辑更改或开始导出。

历史交付保留原文件、确认时间和意见，按原范围只读显示；需要审阅当前剪辑时先重新导出，再对新记录添加意见或确认。
