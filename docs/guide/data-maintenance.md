# 本机数据维护

在设置 → 数据中可以查看空间、设置自动备份、恢复副本和清理无引用素材。这些接口只在本机免登录模式开放，登录部署不会向远程用户暴露本机路径或整个数据库。

## 备份与恢复

默认每 24 小时备份，保留最近 7 份；间隔和保留份数可以修改。只有服务运行时才执行调度，错过的到期备份会在下次启动后补做。失败原因会保存在设置里，15 分钟后重试；新备份成功前不删除旧备份。也可以随时点“立即备份”。

备份位于 `data/maintenance/backups/<id>/`，包含 SQLite 一致快照、全部登记素材及衍生物、平台配置、模型默认值、本机插件，以及字幕识别的持久任务 journal（包括 unknown / pending 状态）。它也包含账户、会话和平台密钥，只保存在本机；目录权限为 `0700`，文件权限为 `0600`（插件可执行文件为 `0700`）。它与可分享的 `.plein` 项目包用途不同。

“恢复副本”先逐文件校验大小和 SHA-256，再校验 SQLite 完整性以及登记素材的完整性，最后在 `data/maintenance/restored/<id>/` 生成独立数据目录。当前数据不会被覆盖。恢复后先关闭 Plein，再将 `PLEIN_DATA_DIR` 指向返回的新目录；桌面端也可以在完全退出后，将副本内容复制到原数据目录。原目录和副本都先保留，确认工作正常后再自行移除旧目录。

源码安装还可以在离线时执行：

```sh
pnpm --filter @plein/server exec tsx scripts/restore-backup.ts /absolute/path/to/backup /absolute/path/to/new-data
```

目标目录必须不存在。恢复过程中断或校验失败不会发布半份恢复目录。备份不包含临时文件、其他备份、回收站、先前恢复的副本或 CLI 代理的工作目录；数据库中的历史记录仍然保留。平台账户的远端状态由平台维护。

## 空间与清理

空间分类包括数据库、原始素材、衍生物、临时文件、备份、回收站、恢复副本和其他文件。按内容哈希统计素材数量，多个所有者持有同一文件不会重复计算物理空间。

默认只考虑登记时间和磁盘修改时间都超过 30 天、且完全无引用的素材。画布当前采用项与全部历史候选、任务输入与已记录的远端结果、字幕识别 journal、资产库及版本、模板、命名检查点共同保护素材；即使原画布已删除，命名检查点仍会保护引用。共享文件在全部所有者都无引用时才可清理。无法解析文档或遇到符号链接时停止清理。

先点“检查可清理素材”审查数量和字节数，再确认移入回收站。预检令牌 10 分钟后过期；确认前数据有变化，必须重新检查。上传、衍生物生成或项目导入进行中不会执行清理，备份和清理之间也不会竞争同一个文件。

回收站默认保留 30 天，在此期间可以恢复全部文件和所有者元数据。移入回收站不会立即减少磁盘占用。到期后调度器再次检查引用，有新引用则恢复整批素材，其余批次才永久清除；中断的回收操作会在下次启动时先恢复。临时文件和无法识别的磁盘文件不在本次清理范围。
