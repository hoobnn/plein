# 在 Plein 和即梦之间协作

编剧可以在 Plein 改一段台词，分镜师可以在即梦改同一段镜头提示词。打开 Plein 画布工具栏的「即梦同步」，选择对应画布，再逐张比较和传递改动。Plein 会记住两边已经关联的卡片。

## 安装并登录

在运行 Plein 本地服务的电脑上安装对应 CLI。「即梦同步」在绑定本机回环地址、采用本地免登录模式的服务中可用。下列命令适用于 macOS 和 Linux。

### 即梦全能画布

```sh
curl -fsSL https://jimeng.jianying.com/canvas-cli/install.sh | bash
dreamina-canvas auth login
dreamina-canvas auth status
```

### 即梦短剧

```sh
curl -fsSL https://jimeng.jianying.com/novel-cli | bash
jimeng-novel login
jimeng-novel status
```

两个 CLI 各自保存授权。也可在 Plein 的「即梦同步」面板发起所选平台的授权，在官方页面确认后回到面板核对登录状态。授权页过期时可重新开始。短剧安装包还包含 `jimeng-drama` Skill，用于准备故事设定、分集剧本、角色和场景卡、分镜及成片。Plein 同步可直接使用已有画布。

## 选择项目并读取差异

1. 打开要协作的 Plein 画布，点击「即梦同步」，选择「即梦全能画布」或「即梦短剧」。
2. 点击「我的即梦项目」并选中项目，也可以粘贴项目链接或 ID。全能画布使用 UUID。短剧默认列出 CLI 当前空间的项目，可以在面板中切换到个人或团队空间。短剧链接中 `projectId` 是项目的数字 ID，`canvasId` 表示另一个对象。也可直接输入「空间 ID/项目 ID」，例如 `0/1000` 表示个人空间中的项目。
3. 点击「读取差异」，选中一行，核对两侧的标题、正文与节点 ID。可按状态筛选，也可用标题、正文片段或节点 ID 搜索。点「定位到画布」会选中对应的 Plein 节点，点「打开即梦画布」可到即梦核对原稿。首次使用时，即便两张卡同名，也需要分别确认来源。
4. 选择「导入 Plein」会在当前画布建立与来源相应的节点。选择「在即梦创建」会将本地节点写成对应平台支持的草稿类型。再次读取同一项目，即可看到每张关联卡的修改状态。

读取成功后，在同一浏览器标签页重新打开这张 Plein 画布的同步面板，会预填上次读取的即梦项目。点击「读取差异」即可查看最新版本。

批量导入时，先勾选「仅即梦有」的卡片，或点「选择当前可导入项」，再点「导入所选」。可以切换筛选条件继续勾选，面板会显示筛选外已选的数量。每批最多导入 200 张。

选择「编辑时同步已关联节点」后，Plein 在编辑当前画布时立即检查一次，每轮结束 30 秒后再检查。单侧修改会传递到另一侧，双方均已修改的卡片留给你核对。离开当前画布或关闭开关会停止后续轮询。新卡片和媒体文件由你在面板中选择后传递。

## 从 MCP 协作

外部 AI 可以直接读写同一组草稿。先指定 Plein 的 `canvas_id`，再选择即梦项目。每次操作使用对应 CLI 在这台电脑上的现有账号。需要登录时，在同步面板或官方 CLI 完成授权。`external_canvas_status` 可查询登录是否完成。

| 要做的事                                       | 使用的工具                                                                      | 令牌权限                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 查看已有绑定、选择短剧空间或查询两种平台的项目 | `external_canvas_targets`、`external_canvas_spaces`、`external_canvas_projects` | `read`                                                                |
| 比较卡片、逐段读取两侧正文、合并预览和参考项   | `external_canvas_preview`、`external_canvas_read_row`                           | `read`                                                                |
| 将选定的新卡导入当前 Plein 画布                | `external_canvas_pull_new`，每批最多 200 张                                     | `edit`                                                                |
| 逐卡采用、写回、合并、解除或核对关联           | `external_canvas_apply`，选用预览中该卡的 `actions`                             | 导入新卡、核对创建结果用 `edit`，覆盖、合并或解除关联用 `destructive` |
| 选择媒体并将指定版本放进当前画布               | `external_canvas_media_list`、`external_canvas_media_import`                    | 查询用 `read`，导入用 `edit`                                          |
| 发布素材到全能画布，或替换短剧当前所选素材     | `external_canvas_media_publish`、`external_canvas_media_replace`                | `destructive`                                                         |

写入前，外部 AI 会收到待确认的目标、操作和影响范围。查看并同意后，AI 用相同参数加 `confirm: true` 执行。草稿采用本次预览的 `target`、`resolvedTarget` 和每行的 `rowId`、`revision`。短剧媒体采用列表返回的带空间目标、`nodeId` 和 `assetId`。当版本变化或空间无法验证时，重新选择目标再核对。每次 MCP 调用只处理本次选择的内容。编辑器中的持续同步单独由面板开关控制。

## 从剧本到镜头

| 创作对象                         | 即梦内容                                                                          | 在 Plein 中编辑                                                         |
| -------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 短剧故事设定、分集大纲、每集剧本 | 文本卡的名称和正文。官方 Skill 常用 `story/setting`、`story/outline`、`story/E01` | 卡片标题和 Markdown 正文                                                |
| 短剧角色、场景                   | 角色名、场景视图名及描述                                                          | Plein 角色或场景节点的名称、描述                                        |
| 短剧分镜、图片、视频、音频       | 媒体卡名称及生成提示词。分镜常用 `E01/S01` 一类 key                               | 图片与视频使用对应的 Plein 生成节点，音频提示词作为 Markdown 文本卡导入 |
| 全能画布文本和生成草稿           | 文本正文、媒体提示词或描述。CLI 提供完整可写配置时可写回媒体草稿                  | 标题和正文；支持位置的顶层节点还可同步坐标                              |
| 全能画布主体与时间轴             | 主素材、音色、辅助素材及有序轨道片段                                              | 导入包含来源和顺序的 Markdown 只读摘要，完整编排留在即梦                |

拖动组内节点时，分组的父坐标系会影响位置。分组、连线、候选结果和音色由各平台继续管理。在 Plein 中新建的角色、场景、图片和视频节点可创建为即梦短剧同类草稿。全能画布可接收文本、图片和视频草稿。保存图片或视频草稿会保留提示词，之后可在对应平台的生成入口执行生成。

短剧分镜的实际生成参考按原顺序展示。可查看别名、普通参考或首尾帧用途。来源能按项目内唯一的节点 key 核实时，点击参考名即可查看来源卡片，返回后会恢复原来的搜索和分镜。外部素材可能没有来源节点。人工连线及残留旧线也可能出现在画布上。核对下一次生成将使用哪些素材时，请以分镜的参考列表为准。

## 传递已选素材

### 从即梦导入 Plein

在差异列表选中远端节点，在「即梦媒体素材」中核对名称和素材 ID，点击「将此素材导入 Plein」。全能画布按节点列出成功的候选，存在多个版本时需要选择具体版本。短剧列出当前采用的版本，角色和场景支持导入已采用的设定图。

Plein 校验下载的文件后，将原件保存到素材库并在当前画布建立原生图片、视频或音频元素。向同一 Plein 画布重复导入同一远端节点的同一版本，会复用此前导入的元素。若已在 Plein 为该元素更换素材，界面会提示核对原件。

### 从 Plein 导出到全能画布

在目标全能画布点击「导出 Plein 素材」，选择媒体类型、素材和「保存到即梦画布」。图片、视频和音频原件会上传到指定项目，并成为新的同类媒体节点。再次导出同一素材到同一对画布时，Plein 会按原发布身份核对已有节点。已确认发布后在即梦删除或替换该素材时，再次导出会提示核对。

### 替换短剧当前素材

选中已有图片、视频或音频素材的短剧节点，点击「选择 Plein 素材替换」，选定同类型原件，再点「替换即梦当前素材」。Plein 核对项目空间与当前选片，上传后重新检查才绑定新资源。短剧 CLI 接受最大 128 MiB 的单个文件。上传期间有人换片时，刷新列表核对目标，已上传的文件可能留在即梦素材库。

## 处理冲突或中断

- **一侧已修改。** 核对差异并选择希望保留的版本。远端项目发生更新后，重新读取差异即可查看新内容。
- **可合并。** 例如在 Plein 改了正文，分镜师在即梦改了标题。检查合并预览后点击「合并两端改动」，两处修改都会保留。拖动卡片按一次完整的位置修改处理。
- **双方修改了同一字段。** 两侧内容会并排展示。长剧本会折叠首尾相同的行，点击「展开完整正文」可查看上下文。要合并同一段台词中的不同改动，可先在 Plein 的卡片里整理成定稿，再重新读取，选择「用 Plein 版本更新即梦」。选择单侧版本会覆盖另一侧卡片上对应的同步字段。
- **待核对创建结果。** 刷新并按节点 ID 核对刚才的创建。若界面提供待关联对象，先打开即梦确认是哪张卡，再在 Plein 关联。确认即梦没有创建副本后，才解除记录并重新创建。
- **一侧的卡片被移除。** 查看现存一侧的版本，再决定是否重新导入或解除关联。「解除关联」只清除 Plein 保存的对应关系，两侧现有卡片仍可独立编辑。

同一台 Plein 服务会按顺序处理对同一即梦项目的操作。如果手动刷新和后台轮询同时读取同一对画布，两者可共用一次读取。写入之后到达的刷新会等待写入完成，再读取结果。两种官方 CLI 保存节点时都缺少远端版本条件。如果协作者在 Plein 最后一次读取与保存之间从即梦网页、另一台 Plein 服务或 CLI 修改同一字段，后保存的内容可能覆盖先前修改，请刷新后核对。

## 适配约定

节点关系以平台、项目 ID 和稳定节点 ID 定位。新的同步字段应使用官方 CLI 可读、可局部写入并可回读验证的合同。素材选择按资产 ID 核对。短剧的可见连线从来源指向使用者；即梦在更换生成参考后仍可能保留旧线。核对分镜实际使用的参考时，应读取该节点的生成配置，保留素材别名、顺序、首帧与尾帧用途。
