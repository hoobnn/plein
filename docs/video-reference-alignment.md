# MiniMax / 火山视频参考对齐验收

日期：2026-10-25。以当前工作区代码为准；工作区已有的仅尾帧和媒体探测改动继续保留。

## 已落地

- MiniMax 模型目录补全 H3、H3-Highspeed、H3-Lite、H3-Max，并按各自时长、分辨率和参考能力校验；开放 21:9 与参考智能画幅，文生视频 / Lite 参考的具体画幅限制前置提示。
- Seedance 2.0 / Fast / Mini 接入 9 图、3 视频、3 音频；2.5 接入 30 图、10 视频、10 音频。2.0 纯音频需要搭配图或视频，2.5 可单独音频。
- 火山视频参考使用私有 TOS 上传和七天读取签名，避免发送未受支持的视频 Base64。配置为空、上传失败或取消时不会提交视频生成。素材全部验证后才开始上传。
- MiniMax / 火山采用各自的大小、时长、尺寸、帧率、编码规则；火山额外校验视频像素面积与 MOV PCM。
- 界面按图片、视频、音频各自编号，点击编号插入提示词；执行前检查越界并转换平台写法。画布普通名字引用保留；角色、场景等参考自动补充最终图像编号对应关系。
- Seedance 的素材输入允许空提示词，公共执行器不再额外拒绝；MiniMax 仍要求提示词。
- Seedance 自动时长和 2.5 的参考 / 编辑 / 延长任务参数已接入；编辑、延长自动保持对应画幅，编辑保持原时长。自动控制项从手动字段隐藏，实际输入展示生效值。
- TOS 官方 SDK 只用于本地签名，网络仍走宿主。使用官方纯 JS 入口，排除 Node CRC 模块导致的 ESM 发布包启动冲突。

配置、素材上限和编号语义见 [模型平台接入](guide/providers.md#minimax-与火山方舟参考模式对齐)。数字编号对应当前槽位，重排会改变对应素材；名字引用的对应关系每次根据最终输入重新计算。

## 验收边界

没有调用真实 TOS 写入、没有提交付费视频生成；账号权限、真实桶策略、平台对素材的接受程度和成片参考效果尚未云端验收。火山视频参考实际使用前须在平台设置填写自己的 TOS 桶、地域及 Access Key / Secret Key；本轮没有更改现有账号配置、桶权限或生命周期。

## 提交前复审

复审修复了以下问题，并补充针对性回归：

1. 前端通用提示词检查与 Seedance 可选提示词合同冲突：有合法素材时不再禁用生成；无素材或仍要求文本的模型继续阻断。
2. 前端只统计显式连线会误拦自动合入的角色参考：存在软引用时由服务端根据最终素材数量校验编号及音频搭配，提交前仍会阻断真实越界。
3. 仅尾帧被所有模型的菜单无条件开放：声明模型已实现的模式，在菜单禁用和服务端预览两个位置阻断不支持的输入。
4. Seedance 2.5 首帧 / 首尾帧会因节点默认 16:9 被拒绝：自动保持输入画幅；MiniMax 首尾帧的实际输入展示也改为跟随输入。自动控制值仅作用于支持的对应平台，避免影响其他平台。

编号解析同时改为每次提示词处理只扫描一次，避免对每个 @ 重复扫描全文。

复审最终验证使用只包含本次改动的独立 Git 索引快照，排除工作区并行的兼容渠道、配方库和首页调整：229 个测试文件通过，2041 项通过、1 项跳过；13 个 TypeScript 项目通过；格式、lint 与相关 Markdown 校验通过；前端构建及服务端发布构建通过。发布构建的三项浏览器验收覆盖编号 / 重排 / 刷新、仅尾帧，以及火山空提示词和不支持模式的禁用。真实云端上传与付费生成仍未执行。
