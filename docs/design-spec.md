# 界面设计规范

原则：外壳克制、尺寸成体系、层级靠材质和阴影区分，颜色留给画布里的作品。所有数值都是 `apps/web/src/styles.css` 里的令牌，组件只用令牌和通用控件类，不写任意值（`rounded-[10px]`、`text-[13px]`、`!h-9` 这类）。

## 配色

- 外壳只用灰阶。`primary` 是黑白反色的主操作（生成、新建、确认）。
- `accent` 是蓝，只表示选中、焦点、链接和运行中。
- 端口和元素类型各有一个颜色（文本、图片、视频、音频、JSON），只用在类型图标、端口和连线上。
- 明暗两套颜色由 `<html data-theme>` 切换，画布 GPU 层的颜色在 `packages/canvas-core/src/theme.ts`，两边数值对应。

## 间距

4 的倍数：2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64。Tailwind 的 `--spacing` 固定为 4px，`p-3` 就是 12，不随根字号变化。

| 场景                           | 值             |
| ------------------------------ | -------------- |
| 浮动外框离视口边               | 12             |
| 浮层之间、工具条离所贴元素     | 8              |
| 工具条、菜单的内边距           | 4              |
| 面板分区内边距                 | 16             |
| 对话框内边距                   | 20–24          |
| 首页栏宽 / 网格间距 / 区块间距 | 1008 / 16 / 24 |

## 圆角

六级，**同心**：嵌套且内边距不超过 8 时，内层圆角 = 外层圆角 − 内边距。

| 令牌          | 值  | 用在                                                      |
| ------------- | --- | --------------------------------------------------------- |
| `rounded-xs`  | 4   | 键帽、复选框、行内代码                                    |
| `rounded-sm`  | 6   | 标签、角标、24 高的小控件、分段控件里的项                 |
| `rounded-md`  | 8   | 28–36 高的按钮、输入框、菜单项、工具条按钮、≤ 64 的缩略图 |
| `rounded-lg`  | 12  | 工具条、菜单、弹层、提示条、大缩略图                      |
| `rounded-xl`  | 16  | 卡片、面板、生成器、画布上的节点                          |
| `rounded-2xl` | 20  | 对话框                                                    |

例：工具条 12 − 内边距 4 = 按钮 8；首页卡片 16 − 内边距 6 = 封面 10。

## 字号

界面正文 13，阅读和输入 14。字重只用 400 / 500 / 600。

| 令牌        | 字号 / 行高 | 用在                             |
| ----------- | ----------- | -------------------------------- |
| `text-2xs`  | 11 / 14     | 角标、键帽、分组标签             |
| `text-xs`   | 12 / 16     | 说明、元信息、小按钮             |
| `text-sm`   | 13 / 18     | 界面默认：按钮、菜单、表格、正文 |
| `text-base` | 14 / 22     | 提示词、Markdown、卡片标题       |
| `text-lg`   | 16 / 22     | 对话框标题                       |
| `text-xl`   | 20 / 28     | 页面标题（故事板、登录）         |
| `text-2xl`  | 26 / 32     | 首页大标题，字距 −0.02em         |

## 控件高度

| 高度    | 用在                                                                                   |
| ------- | -------------------------------------------------------------------------------------- |
| 24      | 分段控件里的项、标签、节点卡片里的小按钮                                               |
| 28      | `.ui-btn-sm`：面板和工具条里的次要操作                                                 |
| 32      | 默认：`.ui-btn`、`.ui-input`、菜单项、贴着元素的工具条按钮                             |
| 36      | `.ui-btn-lg`、`.ui-input-lg`：页面主操作、对话框和设置里的表单；底部和顶部工具条的按钮 |
| 40 / 44 | `.ui-bar-sm` / `.ui-bar` 工具条外框                                                    |

## 层级与材质

| 高度 | 阴影         | 用在                         |
| ---- | ------------ | ---------------------------- |
| 1    | `--shadow-1` | 静止的卡片                   |
| 2    | `--shadow-2` | 浮动工具条、生成器、卡片悬停 |
| 3    | `--shadow-3` | 菜单、弹层、提示条           |
| 4    | `--shadow-4` | 对话框                       |

- `--float`：工具条和生成器，半透明加模糊。
- `--menu`：菜单和弹层，几乎不透明，盖在图片上也读得清。
- 深色主题给浮层顶边加一道 1px 高光（`--edge-light`），浅色主题靠细描边和阴影。
- 对话框是实色 `surface`，不用半透明材质。

## 动效

| 令牌         | 时长  | 用在                     |
| ------------ | ----- | ------------------------ |
| `--dur-fast` | 120ms | 悬停、按下、颜色变化     |
| `--dur-base` | 180ms | 菜单和弹层弹出、卡片抬起 |
| `--dur-slow` | 280ms | 对话框                   |

- 曲线：位移和缩放用 `--ease-spring`，颜色用 `--ease-standard`。
- 菜单、弹层从 97% 缩放淡入；对话框遮罩淡入、面板弹出。
- 系统开启“减少动态效果”时，所有动效和过渡缩短到 1ms。

## 状态

| 状态                   | 表现                                                                |
| ---------------------- | ------------------------------------------------------------------- |
| 悬停                   | `--hover` 底，文字从 muted 变 ink                                   |
| 按下 / 打开 / 当前工具 | `--active` 底                                                       |
| 选中（选项、分段）     | 分段控件里浮起的白底；选项卡片用 `accent-soft` 加 `accent` 描边     |
| 焦点                   | 按钮 2px `accent` 外框、偏移 2；输入框 1px `accent` 描边加 3px 柔光 |
| 禁用                   | 40% 不透明，没有悬停效果                                            |

## 通用控件

| 类                                                                                                                                                                     | 说明                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `.ui-bar` / `.ui-bar-sm` / `.ui-bar-btn` / `.ui-bar-sep` / `.ui-bar-text`                                                                                              | 工具条：页头、底部工具条、结果 / Frame / 多选工具条 |
| `.ui-btn` + `-primary` `-secondary` `-quiet` `-danger` `-danger-solid`，尺寸 `-sm` `-lg`，`.ui-icon-btn`                                                               | 按钮                                                |
| `.ui-input` / `.ui-select` / `.ui-input-lg`                                                                                                                            | 输入框、下拉框（`ui/Select.tsx`）                   |
| `.ui-field` / `.ui-label` / `.ui-help` / `.ui-section-title`                                                                                                           | 表单字段和分组标题                                  |
| `.ui-seg` / `.ui-seg-item`，`.ui-seg-block`（铺满等分，选中底色滑动切换，需传 `--seg-n` / `--seg-i`）、`.ui-seg-tall`（图标在上）、`.ui-seg-aspect`（画幅，最多 9 项） | 分段控件：主题切换、筛选；参数面板选画幅、分辨率    |
| `.ui-menu` / `.ui-menu-item` / `.ui-menu-label` / `.ui-sep`                                                                                                            | 菜单、弹层（`ui/Popover.tsx`）                      |
| `.ui-dialog-scrim` / `.ui-dialog`                                                                                                                                      | 对话框动效（`ui/Dialog.tsx`）                       |
| `.ui-toast` / `.ui-tooltip`                                                                                                                                            | 提示条、悬停提示（`ui/Tooltip.tsx`）                |
| `.ui-chip` / `.ui-badge` / `.ui-kbd`                                                                                                                                   | 标签、图片上的角标、快捷键                          |

新组件先找这里的类；确实需要新的样式时，先在 `styles.css` 加成通用类，再在组件里用。
