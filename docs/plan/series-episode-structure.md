# 剧集、单集与镜头的组织

## 目标

一个项目承载一部作品；项目下管理有序的集，每集管理有序的片段与镜头。画布是自由创作的工作空间，不以画布数量或位置定义内容归属。片段与画布允许多对多关联：一张画布可用于多个片段，一个片段也可在多张画布中制作。没有关联的画布仍可独立创作。

```text
项目（作品） → 集 → 有序片段 → 镜头
                       ↕        ↕
                   画布 / 分镜表 / 生成节点（工作空间）
                               ↓
                         剪辑序列（成片顺序）
```

集、片段和镜头需要稳定身份；序号可调整，不作为身份。当前实现中的镜头仍以画布、分镜表和镜头 ID 组合定位；升级时必须为新业务身份设计明确映射，不能把已有跨画布引用视为已自动迁移。分节边界不必是剪辑切点：跨片段连续镜头需要显式来源和连续性描述，不能凭名称自动合并成一次生成。集、片段及镜头的计划顺序与实际序列中的剪辑实例分开管理。

## 兼容与迁移

- 老项目和未归属画布保持可访问，不能仅凭名称推断集或片段，更不能在升级时自动重排、删除或覆盖原画布。
- 用户主动组织时，创建集和片段并选择画布建立多对多关联。支持集级共享工作区及未归属画布；解除关联不删除画布、素材或镜头。绑定分镜表或镜头到片段应是明确的内容映射，不能从画布关联推断出画布内所有节点都属于同一个片段。
- 当前「学姐第一集重制」拟建立第一集及第 01–53 节的有序片段记录，先将现有分镜表映射到对应片段，并保留已有画布作为工作区。原「gpt 分镜画布」作为原始工作区保留；其旧分镜与新表不能同时计为正式镜头。未来可将多个片段组织在同一工作区，是否合并由实际工作流决定，不自动复制、合并或删除现有 53 张画布。迁移前按画布与分镜表 ID 生成并核对完整清单，不能持续依赖标题识别。
- 保留原有画布、分镜和镜头身份与结果；关联本身不修改提示词、素材、确认记录或生成状态。未完成拆分的 DG-001、DG-074 和跨节 DG-061A/B 保留原始说明并单独复核。

## 必须同时覆盖的行为

1. 持久化集、片段、镜头身份、顺序、内容映射及多对多画布关联，校验项目所有权和跨项目引用；支持创建、重命名、排序、关联、解除关联及删除语义。重新定位或复制分镜表时要明确身份保留、复制或历史来源，不凭标题建立身份。
2. 项目界面按集和片段展示并进入画布，同时展示未归属画布；允许调整顺序，不把画布最近修改时间当剧情顺序。
3. 项目包导出、导入及 ID 冲突重映射保留层级与关联；旧包仍可导入为未归属画布。检查点恢复为新画布时，明确其归属处理，不自动继承可能失效的制作确认。
4. 汇总集的分镜与制作进度时按实际关联计算，区分未展开、未生成、已生成、已采用和人工验收；跨画布只读汇总不冒充已交付成片。
5. 交付顺序使用明确的集级剪辑方案；不能把分镜计划时长或画布顺序视为已生成视频或已确认的成片。

## 验收

- 旧数据库升级后，已有项目、画布、资产和检查点可正常打开；升级失败可恢复。
- 新建多集、多个片段及未归属画布；验证一画布多片段、一片段多画布，画布关联不自动绑定全部镜头；重排、移动、刷新、重启后关系正确，跨项目关联被拒绝。
- 项目包在新库和有 ID 冲突的库中往返，层级与画布映射正确；旧版项目包导入不丢画布。
- 以真实用户数据的副本核对第一集的 53 项映射；保留原画布及素材，对跨节连续镜头和未拆切镜给出明确状态。
- UI 能从作品进入集、片段和画布，并正确呈现空态、未归属项和加载错误；不触发生成或把内容标记为人工审核。
