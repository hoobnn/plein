# E1 静态 3D 构图实验

2026-10-15。工具已实现（见 [0.2.0 路线图 · E1 实现记录](roadmap-0.2.0.md#e1-实现记录)），对照实验还没跑：要在真实平台出图，先报调用次数，用户批准后再跑。

实验只回答一个问题：同一组镜头，给图片模型加一张 3D 构图截图作参考，比只用文字描述构图，能不能更少次数拿到可采用的镜头，摆场景花的时间是否值得。编辑器运行通过不代表生成模型会严格复现空间。

## 设置

- 镜头：固定 6 个，覆盖常见的构图要求，每个都在 3D 构图里摆好并截图。

  | 镜头 | 要求                                           |
  | ---- | ---------------------------------------------- |
  | 1    | 两人对峙，左右分站，中景，机位平视             |
  | 2    | 过肩：前景一人背影占左三分之一，另一人正对镜头 |
  | 3    | 低机位仰拍，一人站立指向画外                   |
  | 4    | 一坐一站，桌子把两人隔开，坐着的人被桌子挡住腿 |
  | 5    | 远景，人物很小，站在门边，墙占画面右半         |
  | 6    | 9:16 竖画幅，一人跪地，另一人伸手              |

- 两组条件，除了参考图其余完全相同：
  - **A 文字**：提示词写清人物位置、景别、机位和遮挡；
  - **B 文字 + 构图**：同样的提示词，前面加一句「按参考图 1 的构图、机位和人物站位」，3D 构图节点的「构图」连到图片节点的参考图。
- 模型与参数：方舟 Seedream 图片模型，同一分辨率和画幅，不开智能画幅；两组都连同样的角色设定卡参考图。模型 ID 与版本记进结果。
- 每个镜头每组出 3 张，共 6 × 2 × 3 = **36 次付费调用**。

## 审片标准（实验前定死）

每张图按四项各打 0 / 1 / 2 分：

| 项         | 2 分                     | 1 分     | 0 分             |
| ---------- | ------------------------ | -------- | ---------------- |
| 人物位置   | 左右、前后关系都对       | 只对一项 | 都不对或人数不对 |
| 景别与机位 | 景别和机位高度都对       | 只对一项 | 都不对           |
| 朝向与姿态 | 朝向、姿态都对           | 只对一项 | 都不对           |
| 遮挡       | 该挡的挡住、不该挡的没挡 | 部分对   | 不对             |

「可采用」：总分 ≥ 7，且角色外观没有跑偏（和设定卡比对）。审片时把 A、B 两组的图打乱顺序、遮住组别，由同一个人打分。

## 记录

| 指标                     | 怎么记                                                 |
| ------------------------ | ------------------------------------------------------ |
| 构图接近程度             | 四项得分，按镜头和组别汇总                             |
| 达到可采用结果的生成次数 | 每个镜头在 3 张内第几张第一次可采用；3 张都不行记为 >3 |
| 摆场景时间               | 在 3D 构图里从空场景到截图的计时（分钟）               |
| 成本                     | 实际调用次数和平台账单金额                             |
| 失败样例                 | 0 分项多的图连同提示词、参考图存档                     |

## 判定

B 组满足下面任一条，且摆场景平均每个镜头不超过 3 分钟，才规划动态轨迹 / 视频输出：

- 可采用率比 A 组高 20 个百分点以上；
- 每个镜头达到可采用的平均生成次数比 A 组少 30% 以上。

否则 3D 构图保持实验状态，不再扩展。
