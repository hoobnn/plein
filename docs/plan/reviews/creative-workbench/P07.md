## 已核实的复用点与缺口

现有 `StoryboardReview` 已有逐镜候选状态、参考、创作验收、单项生成与连续性回放；`CreativeReviewForm` 的结论按具体候选保存；`StoryboardSync` 支持显式同步并保留节点手改。P05 提供固定原文／映射和只读定位，P06 将提供计划／观察／依赖的公开读取与小表单，P10 提供可编辑控制草稿。工作台应组合这些能力，不新建审片或执行系统。

当前最近任务／逐节点 latest 接口不能保证找回一个较老采用候选的冻结输入。需要一个按 canvasId + runId 读取具体 JobInfo 的只读接口，核对拥有者、画布、nodeId 和候选 runId；没有旧记录时显示未记录，绝不能用当前参数填成旧候选依据。

## 已独立复核的最小合同

- 以当前画布、稳定分镜／镜头 ID 为目标；从引导的代表镜头及分镜行进入。一次仅挂载一镜的媒体／候选，切换与关闭显式停止播放器，不给大分镜预加载全部视频。
- 同屏显示镜头目的、画面与生成字段，固定原文链接、当前引用、P06 计划／观察、已采用候选与历史候选、生成时实际输入和当前实际输入并列；目的使用 P06 的真实计划字段，不将画面描述改名充当目的。
- 编辑只写明确目标并保留其他字段与镜头；已有节点通过原差异面板显式同步。控制草稿复用 P10，入口提供当前工作台身份校验，不依赖被关闭的旧分镜表。
- 候选预览不自动采用，旧候选保留。记录验收继续使用原具体候选合同；迟到输入／任务响应、切换目标、候选变化及只读／viewer 同时检查。
- 局部重生成继续使用原输入冻结和执行关卡，显示具体目标、有效输入及价格未知，不从工作台打开或参数编辑自动生成；仅选择的镜头／角色进入清单。
- 定位到原画布／序列，显示真实下游引用影响。待检查、陈旧输入、失败／提交未知和人工可用分别展示，不把零节点或任务成功当创作完成。

## 预定验收

使用 P01 同一输入，至少完成一条本地受控路径：发现问题→查看固定剧情／旧候选依据→只改目标→显式同步→仅视频生成新 mock 候选→记录该候选审片→查看相关下游影响。核对旧候选和未改镜头保留，整个路径的实际 submit 与人工动作分开计数。

另覆盖旧项目缺新字段、多分镜／同镜号、被删除对象、历史 JobInfo 超出最近窗口、只读／viewer、同帧目标改变、迟到响应与关闭媒体释放。单项相关测试和独立复核完成后才放行 P11。
