## 范围与合同

HTTP 与 Agent 按原始 `NodeRuns` 实例共用 `StoryboardBatches`。`run_storyboard` 保留既有 `id`、`role`、`shot_ids`，增加只读 `preview_only`、短期 `token` 和显式 `reuse_existing`。未指定镜头默认补缺，指定镜头默认创建新候选；可显式选择复用。四种生成类型都经现有 reviewed batch 排队，统一返回 `group_id`，后续使用 `wait_for_group`。

Agent 先准备清单，再按原 `auto/rules/always` 模式处理。批准闭包只提交原令牌，输入变化返回 `input_changed` 和新清单，不自动执行新范围。自动模式不生成虚假的人工批准。预检作为 read effect 可在计划模式使用，真正执行仍受计划与确认关卡约束。

审批卡片与 UI 批量窗口复用只读 `BatchPlanDetails`，展示目标、沿用、阻塞、跳过、实际模型、提示词、参数、参考顺序、音色和价格未知项。审批历史只持有 `Omit<StoryboardBatchPlan, 'token'>`，没有从历史恢复可执行令牌的路径；本次没有新增文档或项目包字段。

## 独立复核与复查
