## 内容与身份合同

分镜的 `production.sourceMap` 使用预建嵌套 Y.Map，分别保存来源、完整固定快照、人工范围、镜头关联、改编提案和显式已读状态。原文和映射不进入生成 `params` 或输入 hash，不产生模型任务。

- 从实际 `script` 输入连线按稳定顺序读取真实来源端口。Markdown 读取正文，`plein/text` 读取当前文字参数，生成节点读取该端口当前采用候选的文本及 `resultId`。没有可读文字时明确显示原因，不执行上游，也不把索引预览当作全文。
- 快照保存完整未改写原文和捕获时的 `canvasId/elementId/port/resultId`。固定版本不可原地编辑。来源修改、重排、取消连线或删除，只产生提示；用户再次固定时追加版本，不把相似对白自动绑定到新版。
- `originAtCapture` 表示历史出处；`SourceEntry.binding` 表示当前文档中的定位。二者独立。外部或已删来源保留历史，不按同名元素重绑。
- 用户选择固定原文中的准确 UTF-16 范围，人工声明事件或对白。范围不能越界、为空或切开代理对。重复对白因版本和范围不同而具有不同稳定 ID，没有语义匹配或自动因果判断。
- 原文可以关联多个稳定 `shotId`，API 同时支持明确的 `dialogueId`。处理方式为保留、压缩、合并。镜头重排不改变关联，内容修改显示待复核，镜头删除显示缺失，不按镜号寻找替代镜头。
- 用户可以明确将标注划为范围外。改编提案可以没有原文范围，界面明确显示“提案（非原文）”。已有模型草稿、人工镜头内容和提示词均不重写。
- 已读必须点击“我已核对本版原文”，打开、滚动、选择范围都不替代该声明。未读、未映射、待复核和有意范围外分别展示；未标注的原文仍需人工检查，标注数不等于叙事完整性。

## 确认、协作与副本

P03 的完整内容快照加入当前固定版本及对应人工标注、镜头映射、范围决策和提案。首次固定原文、新固定版本或映射修改使旧内容确认过期。已读、滚动、展开及来源节点查看不进入签名。没有来源数据时保留 P03 原有分镜 JSON 格式，空迁移不会作废已有确认。

内容确认针对固定版本。上游后来修改不替换已固定原文；界面持续提示当前来源与固定版的差异。原确认因此不能被解释为已核对新的上游文字。内容确认仍不授权执行。

每项写入采用当前本地 origin 的独立撤销事务。首次来源身份采用当前分镜作用域内 elementId 与 port 的确定性键；两端同时首次固定同一来源只形成一个 active 指针，所有独立快照保留。共同初始化后的协作者追加不同标注不会替换整份来源数据；本地撤销不会删除远端追加。schema 8 到 9 只预建空结构，不猜测旧来源或历史映射。未来版本继续只读打开。

复制、模板、检查点恢复及 `.plein` 包导入会建立新的来源、快照、范围及关联身份。共同复制的当前来源绑定重映射到对应副本；未复制的外部来源明确解除当前绑定，保留原出处与原文。镜头身份继续由新分镜作用域与稳定 `shotId` 限定。原生产确认保留原 scope 并显式标记为历史；普通复制、模板、恢复和包导入均不继承当前确认，即使 fresh 导入保留原 canvasId／boardId。副本清空已读声明。

UI 保存时即时重查当前 engine、画布、分镜、文档只读状态及 session principal。缺少 principal 或 viewer 不可保存固定原文、标注、已读、关联或提案。当前来源在捕获前再次比对全文和采用结果身份，迟到的旧界面操作不能固定用户未看到的修改。

## UI 与有界读取

分镜表新增“剧情来源”视图，支持固定全文、人工划定事件或对白、选择镜头关联、原文到镜头及镜头到原文定位、范围外决定与新增提案。原文存储全文，编辑器按段读取和显示；列表仅显示摘录。

浏览器 textarea 会把 CRLF/CR 显示为 LF，因此界面明确进行显示偏移与原文偏移的双向换算。显示值采用 LF，避免受控值反复赋值重置选区；键盘、指针和失焦均保存实际选区。不能以显示偏移冒充原文位置。选区携带 snapshotId，首次选择即固定所见版本；协作者推进 active 后不能把旧选区套到新版。

现有 Agent `get_element_field` 可沿 `/production/sourceMap/snapshots/0/text` 等 JSON Pointer 有界读取全文，续读携带版本；本项没有新增自动提取、生成或批准工具。
