## 数据与行为合同

目标按 `{canvasId, boardId, sequenceId?}` 精确绑定。每份修订有独立 id、完整 content／snapshot、parents、真实界面操作人、时间及可选复制来源。规格、时长范围、对白／镜头原声／配乐／音效、字幕、允许有意静音／黑场和补充创作文字分别保存；空字段保持未约定。P12 可绑定具体 `goalRevision` ID 与内容快照。

目标不进入 params、生成输入哈希或分镜内容确认快照。修订目标不表示既有分镜、候选或交付满足新要求，不自动改变采用项、模型、序列设置或执行授权。自由文字始终待人工核对，技术设置的比较不能充当实际输出检查。

并发完整版本按 record ID 分别追加。多个 heads 明示冲突，只有明确保存合并版本才形成唯一当前目标；迟到保存检查原 heads、当前画布／分镜／序列及最新只读／用户权限。读侧深冻结目标历史，写入和返回对象隔离，避免修改缓存对象改坏历史显示。

复制／模板给内部 board／sequence 和新目标修订映射新身份，origin 保留来源。外部序列或未知目标画布只保留历史；删除后同名对象不继承当前目标。检查点与项目包保留目标内容并明确映射新画布范围；目标不是内容确认，原分镜确认仍遵守 P03 的历史边界。

总览复用 `creationGuideFacts` 和现有镜头身份函数，分列已有产物、已采用、候选自身的人工可用、当前交付确认。旧输入／已保留结果、未采用候选、失败及 `submit_unknown`／恢复任务分别展示。任务按当前节点集合读取最新记录，不依赖最近任务窗口；读取失败保留未知，不从聊天或运行成功推断完成。

当前 Project 只列现有画布链接，不加载其他文档、不聚合猜测其进度。打开、查看、保存目标和定位均不生成、不自动采用、不调度任务。
