# 短剧漫剧画布：创作流程与 Plein 改进计划

目标是让创作者从已有故事走到可审阅、可返工的成片，重点关注剧本、资产、分镜与镜头之间的交接。

## 创作者的工作顺序

1. **定义这一集**：写一句话梗概、类型、画幅、目标时长、人物目标、冲突和结尾；已有剧本可直接导入，先校对场次、人物、对白和动作。不要把所有剧本强制改成同一种钩子或时长。
2. **准备可复用资产**：先确定主角外貌、发型、服装、辨识特征和声音，再按实际需要准备定妆、不同角度和表情；场景记录空间布局、时间光线与常用机位，关键道具记录外观与剧情作用。区分候选、已采用和人工认可；缺乏依据的设定由人补充。
3. **逐场拆镜**：先确定情节节拍与时长，再写景别、人物位置、一个主要动作、对白、声音、画面构图和运动；核对全片时长、原文覆盖以及人物朝向、服装、道具和空间变化。图片提示词描述静态画面，视频提示词描述动作与镜头运动。
4. **试做与定稿**：挑能代表主角、场景和动作难度的一镜，检查实际参考图和模型输入，生成候选后人工挑选；用分镜图和已有声音做节奏样片，先审故事节奏，再批量制作。
5. **生成、返工与交付**：分阶段查看任务和失败原因；只重做受影响的镜头。需要连续动作时查看相邻首尾帧；剪辑中保留独立配音、音效和字幕，回看实际导出文件并逐项处理意见。

## Plein 对照与优先级

Plein 已有短剧模板、资产卡与角色图片槽位、分镜表和原文映射、提示词补齐、参考图检查、样片、批量清单、续镜、候选审核和实际成片回看。角色档案已有时期、服装、表情及状态音色；场景已有命名视角；制作目标已有时长区间，制作总览已有分镜计划时长。问题重点是这些能力分布在不同入口，创作者很难从当前镜头理解需要准备什么，也难以在分镜编辑时对照同范围的目标和证据。

### P0：让第一条创作路径可信

- 模板默认剧本、镜头数量和时长指导保持一致，并允许用户按作品修改；本次已调整新插入模板的默认提示词，不改已有画布。
- 在分镜表就近显示已有制作目标的时长区间及本表计划时长，与现有制作总览共用口径；只有目标范围明确对应本表时才比较。目标未知、存在并发版本或范围不一致时说明原因，不将计划之和当成实际成片时长。验收：改时长后即时更新；多分镜表不会混算；手工导入与旧文档可用。
- 把原文覆盖、角色／场景未绑定、缺参考图和提示词缺失合并为可定位的准备清单；区分客观缺失、建议与人工审核，允许跳过。验收：修复后状态刷新，误匹配不自动绑定，已有数据不被覆盖。
- 试做引导明确说明选代表镜头、检查实际输入、采用候选、人工审阅、制作样片的顺序；已有引导和批量清单复用同一事实来源。验收：无需调用付费模型即可走到预检；只读和离线状态说明可做的操作。

### P1：减少跨镜头反复准备

- 将角色的固定造型、不同服装和表演参考与场景的时间、机位整理成可见的准备视图，沿用资产库和现有引用规则；明确区分文字设定、参考图存在与人工认可。验收：同一角色的不同造型能被镜头明确选择；引用来源和实际送入图片一致；旧资产无需迁移即可继续使用。
- 在场景准备中并列展示空间总览、命名机位和对应镜头引用；支持记录人物初始位置、走位和固定物件，但不声称生成图自动遵守方位。复用已有场景视角档案与 3D 构图，生成前核对实际引用。
- 提供按场次或叙事段落筛选分镜、素材与任务的视图，保留自由画布；镜头顺序仍以分镜和序列为准。与现有 [剧集、单集与镜头组织方案](series-episode-structure.md) 统一身份和迁移设计，不以分组位置猜测归属。验收：跨画布、未归属和旧项目可访问，筛选不改内容。
- 让相邻镜头审阅更容易记录服装、朝向、位置、光线和动作衔接意见，连接现有候选验收；首尾帧来源缺失时不做自动判断。验收：意见绑定具体候选，换候选后需重新审阅。

### P2：规模化与交接

- 实现项目、集、片段及镜头的有序组织，按现有剧集方案处理稳定身份、旧数据、项目包和跨画布关联；提供集级进度，但不把生成成功当人工通过或交付。
- 按选定范围展示预算估算、任务进度和可恢复错误，明确未知价格与自动重试；复用现有生成授权和恢复机制。
- 增加可分享的项目交接摘要：原文版本、资产选用、镜头状态、未解决意见和实际导出版本；导出时明确缺失素材与历史记录的范围。
- 在已有共享素材与剪辑实例基础上设计“多镜头一段生成”的制作计划：明确一段包含的叙事镜头、段内时间和候选来源，也允许独立逐镜生成。先做显式映射和人工校对，不能假设模型一定遵循段内时间或自动完成切镜；避免与剧集方案中的镜头身份重复建模。

## 验证方式

先以一段已有剧本完成导入、资产准备、拆镜、选代表镜头、样片和预检；再用多场、多角色、服装变化和一处续镜的样例验证返工。记录每一步从哪里进入、是否找得到下一步、是否理解哪些操作会调用模型、一次修改影响哪些镜头。产品改动需覆盖旧画布、只读、撤销、刷新及多分镜表；真实模型生成和人工内容质量另行验证。

## 深入拆解：从创意到一段可制作的内容

### 剧本：先确定戏的作用，再决定怎么拍

- 一段戏应先规定它回答什么问题、情绪如何收束，再把问句、回答、动作和笑声拆成节拍并估时。创作者应能看到“原文 → 人工标注的事件／对白 → 对应镜头”的路径，也能保留为视觉化新增的提案；没有映射不等于原文一定遗漏。Plein 的原文固定、标注、提案及版本变化提示已经存在，优先把它们从镜头工作台带到用户眼前。
- 时长核对应先按台词的实际或估算朗读、停顿、反应及动作估算，再看整个片段是否装得下。不能用固定语速自动判断艺术节奏，不能因为台词短就强行砍镜。先给人工填写的时间与可选配音实际时长，缺数据时显示未知；是否冲突由创作者确认。
- 短剧、科普、广告和动作片的创意入口不同：短剧强调人物关系与情节变化，科普强调事实、解释和视觉示例，广告强调产品与展示重点，动作片强调起始状态、动作和落点。模板可以给不同问题清单，不能把某种节奏、比例或开头钩子变成通用强制规则。

### 角色和场景：一份身份，多份可选状态

- 同一角色常需要三视图、同框身高对照、不同时期（如现代与少年）的造型，角色身份、时期、服装、表情和音色分别变化。Plein 已有对应档案；镜头工作台应显示本镜实际选择的时期、服饰和声音，并可跳到档案调整。关系无法唯一识别时明确要求选择，不能按相似名字自动固定。
- 角色外貌锚点、声音、舞台位置与全局风格应分开描述；实际输入需展示素材用途和顺序。图片、音色可用不代表已通过人工审核，也不保证模型遵循。角色关系图／身高对照图可先作为普通共享参考素材使用，等真实需求验证后再设计专用数据结构。
- 场景设计和调度通常先建立空间参照，再决定从哪里拍；Plein 已有场景视角、全景投影和 3D 构图。先让用户在本镜看到关联场景／视角与构图截图、能定位来源；空间关系以创作者记录为准，不能从生成图片推断方位准确。

### 分镜：同时可读、可追溯、可修改

一份好用的分镜每镜都能看到景别、构图、人物位置、动作、对白、声音和转场，且转场与下一镜动作相关。对 Plein 的建议不是把长提示词原样塞进每个镜头，而是：

1. 镜头列表保持轻量，显示镜头目的、原文范围、人物／场景、计划时长和关键待办；选择一行后，在工作台编辑细节。
2. 利用现有镜头目的、起止状态、对白及连续性审阅，展示“上一镜结束 → 本镜开始”的对照；建议项只提示，不自动宣称一致或阻断创作。
3. 静态关键帧和动态镜头分开写：前者关心主体、空间、景别与光线，后者说明动作、运镜、声音和变化；显示合成后实际文本供修改。已有提示词和手动覆盖不自动替换。
4. 宫格适合探索景别或构图，但一格不是自动定稿；用户明确切分、比较、采用后才能成为所选镜头参考。复用现有宫格切分、分镜组与候选采用。

### 镜头：区分叙事计划、生成任务和剪辑实例

- 一个叙事镜头可以独立生成；一段生成也可以包含多个镜头或连续运镜；一个生成结果还可能被多个剪辑实例使用。不同身份不能因为顺序相同就合并。现有固定素材、共享实例和剪辑映射已覆盖生成后复用，尚需明确生成前多镜头计划的表达。
- 多镜头计划应记录段内计划时间、各镜的原文／资产、转场及预期声音，并允许导出一份可编辑提示词；校验时间范围与模型参数时展示限制。实际素材回收后由人标定切点并映射，不将计划时间当成真实视频时间。
- 当要接续动作，先让用户选择前段具体候选及取帧时间，再展示来源和已过期状态；已有续镜与相邻镜头审看能力应复用。非连续叙事或转换场景可独立生成，无需强制接尾帧。
- 长段探索会产生大量副本，比较和筛选是日常需求。以候选所属任务、具体输入版本和人工结论组织比较；副本或名称不应自动推断为最终选择。失败和未采用结果仍可查找，不混进当前成片状态。

## 实施切片与验收

| 顺序 | 用户能完成的动作                                                     | 复用与边界                                                         | 完成条件                                                                     |
| ---- | -------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| 1    | 在分镜表查看本表计划时长、目标区间、原文标注与缺失提示，并定位对应行 | 复用制作目标和原文映射；计划、真实成片、人工核对分别显示           | 同范围正确；未设置或并发目标不猜；修改、撤销、重开、只读和多表状态正确       |
| 2    | 在一镜工作台查看并选择人物时期／服装、场景视角、声音与实际参考       | 复用角色档案、视角、绑定和实际输入预览；不新造平行资产库           | 重名和失效引用可处理；实际送入顺序可核对；未送入、仅文字和人工认可明确区分   |
| 3    | 审阅上一镜结束、本镜开始、对白节奏及候选，记录修改意见               | 复用镜头状态、连续性、候选验收和样片；建议非自动判决               | 换候选不继承旧结论；无视频或无音频可继续工作并显示未知；意见可回到目标镜头   |
| 4    | 建立一段包含多个叙事镜头的生成草稿，比较方案后手动映射实际素材区间   | 先完成叙事／生成／剪辑身份及与剧集方案的协议设计；沿用共享素材实例 | 区间冲突、缺素材和改计划有明确提示；复制／导入保留来源；不自动更改成片或重跑 |

建议先在同一段 30–60 秒、多角色对话戏上验证切片 1–3，再补一段动作或连续运镜验证切片 4。以真实使用者记录首次到达预检时间、能否找到未绑定资产、是否能解释一次返工影响；基线与样本不足时只记录观察，不预先宣称效率提升。计划不替代真实模型、声音同步和人工成片验收。
