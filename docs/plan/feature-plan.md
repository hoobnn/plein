# 功能规划与取舍

2026-10-12 · hoobnn；2026-10-14 更新后续优先级。已发布基线见 [0.1.0 路线图](roadmap-0.1.0.md)，下一阶段执行排期见 [0.2.0 路线图](roadmap-0.2.0.md)。

## 结论

2026-10-17 新增 [BeefTV 对照优化工作包](beeftv-optimization.md)，覆盖性能、创作审核、Agent、跨画布素材与检查点；当前实施与验收状态以该台账为准。

Plein 保持“本地自部署的 AI 短剧画布”定位，下一阶段的重点不是增加生成入口，而是让短剧流程可编辑、可复用、可局部返工：资产准备 → 分镜审核 → 创建生成器 → 分阶段批量执行 → 采用候选 → 修正镜头 → 导出。

0.1 已有短剧闭环、稳定引用、基础媒体加工、参考资产与音色绑定、跨项目资产复用和远端任务重启续查，真实样例范围见验收记录。0.1.x 先把已落地的剪辑与资产功能发出去，并补缓存与重连验收；0.2 优先实际输入预览、参考优先级与必需策略、影响分析与局部返工、批次快照、项目迁移和任务恢复；Agent 随主线交付可按范围批准的修改方案。静态 3D 构图先做独立收益实验，完整动态导演台后置。社区、会员积分、团队权限不进入本地单人版。

规划项不代表已经实现，也不承诺任何模型的生成效果。

当前八项创作功能补齐与验证进度见 [本轮台账](feature-completion-2026-10-17.md)。

随后按 P0 → P1 推进的样片、创作验收、持续引导、批量清单、连续性与交付，见 [创作流程优化](creation-workflow-2026-10-17.md)。

## 规划原则

- 批量流程分为“建立生成器”和“执行”两步，下游修改不回写分镜；分镜图与视频生成器之间的自动连接要保留并完善。
- 通用角色卡与平台专属的主体 ID 分开建模，主体 ID 只在支持它的模型上使用。
- 全景、运镜预设、光影提示词都是辅助控制，不等于几何或物理保证；预设可能因场景冲突或模型差异失效。
- “深度参考”指产出深度视频供生成参考，不写成骨骼动捕或 BVH 输出。
- 长视频、真人素材授权等平台特有能力，以公开 API 为准，不据此扩充模型目录；音色克隆的样本时长和保存规则在接入时按供应商合同核对。

### 本地定位带来的追加项

项目包迁移来自 Plein 的本地存储定位：在 P1 做文档 + 素材 + 模板的自包含包，排除平台密钥、Agent 会话凭据和机器绝对路径；迁入新目录后重新检查模型与音色可用性。0.1.0 仍可按 README 备份整个数据目录，不把项目包作为首版发布门槛。

### 资产库的边界

项目 → 多画布结构、资产库五类条目与槽位 / 标签约定、画布卡片与资产库往返、特效卡 `plein/effect` 已经落地。没有做捏脸、换装、AI 美颜等生成式编辑，以及「保存时生成半身 / 情绪九宫格 / 设定图」；这些在画布上用现有三视图、表情九宫格预设生成后存回资产库。官方风格 / 特效只是提示词，不对应 LoRA 或模型专属能力。

## 交互与数据合同

1. **资产引用稳定**：引用持有元素 / 资产 ID，名称用于显示。旧的名称引用迁移时遇到重名不得静默选择；提示用户绑定。文本、图片、视频、音频、主体 ID 的实际输入分别展示。资产卡说明与图像结果必须进入缓存计算，换采用结果后下游提示过期。
2. **分镜更新有方向**：分镜表是镜头计划的事实来源；生成器保留独立参数和手改。记录生成时的分镜版本，表格更新后展示差异，默认不自动更新，由用户选择同步未改字段或保留覆盖；下游不自动回写计划。镜头删除不得自动抹掉已生成素材。
3. **候选、返工可追溯**：生成候选和媒体加工结果都关联来源、任务、参数 / 区间；候选“采用”决定下游消费。裁剪、切分、重生成派生新结果，禁止用加工覆盖原文件。媒体资产存服务端，二进制不放进 Yjs。
4. **能力分层**：本地确定性加工、提示词预设、供应商原生编辑、供应商主体注册分别声明。表单只展示当前 Provider / 模型可执行的能力；泛用 `video.generate` 不代表已支持视频 / 音频参考、局部重拍或主体身份。
5. **分阶段执行**：创建节点和生成计划不自动付费执行。批量图、视频、配音分开，显示目标数量、模型、参数与跳过原因；存在价格配置时显示估算，缺价格则说明未知。失败时只重新运行失败的目标，存在远端任务 ID 则恢复查询；无回执的提交先核查，不直接重发。

## 发布验收与下一阶段门槛

- **0.1.0**：一套 6–10 镜头短剧模板；准备角色 / 场景 / 道具 → 编辑分镜 → 先审图再出视频 / 配音 → 单镜头换候选或修正媒体 → 导出字幕成片。改名、重名、上游变更、手改保留、失败恢复均有明确行为；刷新 / 重启后资产和引用不丢。
- **0.1.x**：发出 0.1.1 之后已落地的剪辑与资产功能（0.1.2），补浏览器缓存与断线重连验收（0.1.3）。
- **0.2.0**：实际输入预览与必需参考、影响分析与局部返工、批次快照与任务恢复为串行主线，项目包迁移并行；Agent 修改方案最小版（按范围批准）随主线交付。分镜组、区域编辑、运镜 / 风格预设、取帧续镜和第三方插件为独立扩展候选，不全部作为发布门槛。
- **0.3.0 以后**：只有在重复创作显示空间控制 / 局部重拍确有价值，且真实后端可用时，推进全景、3D、深度参考和智能剪辑。

流程验收与视觉验收分开记录：mock / 静态检查证明流程和数据关系；真实短样例检查输入是否生效、声画同步、边界衔接和中文字幕；人工回放决定角色一致性与成片可用性。
