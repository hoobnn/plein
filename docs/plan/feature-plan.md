# 功能规划与取舍

2026-10-12 · hoobnn；2026-10-14 更新后续优先级；2026-10-25 并入 0.3.0 之后的未完成项；2026-10-26 更新画布 P0–P2 工程进度。

## 结论

Plein 保持“本地自部署的 AI 短剧画布”定位，重点不是增加生成入口，而是让短剧流程可编辑、可复用、可局部返工：资产准备 → 分镜审核 → 创建生成器 → 分阶段批量执行 → 采用候选 → 修正镜头 → 导出。

已发布的版本覆盖短剧闭环、稳定引用、媒体加工、参考资产与音色绑定、跨项目资产复用、实际输入预览、影响分析与局部返工、批次快照与任务恢复、项目包迁移和 Agent 修改方案，各版本内容见 [releases](../releases/)。静态 3D 的生成收益仍单独验证；本地人物／机位关键帧预演已在本地开发代码落地，当前交付时刻截图，骨骼动画和视频渲染后置。社区、会员积分、团队权限不进入本地单人版。

规划项不代表已经实现，也不承诺任何模型的生成效果。

## 规划原则

- 批量流程分为“建立生成器”和“执行”两步，下游修改不回写分镜；分镜图与视频生成器之间的自动连接要保留并完善。
- 通用角色卡与平台专属的主体 ID 分开建模，主体 ID 只在支持它的模型上使用。
- 全景、运镜预设、光影提示词都是辅助控制，不等于几何或物理保证；预设可能因场景冲突或模型差异失效。
- “深度参考”指产出深度视频供生成参考，不写成骨骼动捕或 BVH 输出。
- 长视频、真人素材授权等平台特有能力，以公开 API 为准，不据此扩充模型目录；音色克隆的样本时长和保存规则在接入时按供应商合同核对。

## 交互与数据合同

1. **资产引用稳定**：引用持有元素 / 资产 ID，名称用于显示。旧的名称引用迁移时遇到重名不得静默选择；提示用户绑定。文本、图片、视频、音频、主体 ID 的实际输入分别展示。资产卡说明与图像结果必须进入缓存计算，换采用结果后下游提示过期。
2. **分镜更新有方向**：分镜表是镜头计划的事实来源；生成器保留独立参数和手改。记录生成时的分镜版本，表格更新后展示差异，默认不自动更新，由用户选择同步未改字段或保留覆盖；下游不自动回写计划。镜头删除不得自动抹掉已生成素材。
3. **候选、返工可追溯**：生成候选和媒体加工结果都关联来源、任务、参数 / 区间；候选“采用”决定下游消费。裁剪、切分、重生成派生新结果，禁止用加工覆盖原文件。媒体资产存服务端，二进制不放进 Yjs。
4. **能力分层**：本地确定性加工、提示词预设、供应商原生编辑、供应商主体注册分别声明。表单只展示当前 Provider / 模型可执行的能力；泛用 `video.generate` 不代表已支持视频 / 音频参考、局部重拍或主体身份。
5. **分阶段执行**：创建节点和生成计划不自动付费执行。批量图、视频、配音分开，显示目标数量、模型、参数与跳过原因；存在价格配置时显示估算，缺价格则说明未知。失败时只重新运行失败的目标，存在远端任务 ID 则恢复查询；无回执的提交先核查，不直接重发。
