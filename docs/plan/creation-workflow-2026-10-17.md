# 从样片到交付的创作流程优化

2026-10-17。用户授权按产品建议的 P0 → P1 顺序落实全部六项。在已有八项创作功能之上推进，保留当前未提交实现、候选采用、任务恢复和本地存储合同。

## 目标与顺序

以更少试错完成一条经过人工审片的可交付短片。P0 先建立分镜动态样片、镜头创作验收与持续引导，P1 再接批量清单、连续性审看和实际成片交付。独立模块可以并行实现，集成验收按此顺序执行。

| 工作包            | 优先级 | 最小交付与验收合同                                                                                                       | 状态 |
| ----------------- | ------ | ------------------------------------------------------------------------------------------------------------------------ | ---- |
| G1 分镜动态样片   | P0     | 分镜图、已有配音、字幕按镜头时长串联；可预览和本地导出；不提交视频生成，不自动识别或配音；与最终成片分开                 | 完成 |
| G2 镜头创作验收   | P0     | 待审、可用、需修改，问题标签与意见绑定确切候选；换候选不继承旧通过；支持筛选与下一待审，保留刷新、撤销及迁移             | 完成 |
| G3 持续下一步引导 | P0     | 可收起任务栏，根据实际文档事实引导到梗概、分镜、一镜、样片、批量和交付；多分镜明确选择，允许跳步；只定位，不自动付费执行 | 完成 |
| G4 批量生成清单   | P1     | 生成前显示运行、沿用、阻塞、原因及调用次数；修复后重新检查；实际输入变化时旧确认不能执行；恢复原任务不混作重新生成       | 完成 |
| G5 连续性审看     | P1     | 上一镜尾帧与当前首帧并排；切点前后片段循环；固定参考图；反馈绑定具体候选，不自动声称 AI 判定连续性                       | 完成 |
| G6 成片回看与交付 | P1     | 回看实际导出的 MP4；时间码意见绑定文件及来源镜头；版本、规格、时长与未解决意见可查；新导出不继承旧确认                   | 完成 |

## 数据与执行合同

- 创作审核、引导和交付确认是工作流元数据，不能进入生成输入或使未变化的镜头重跑。
- 审核始终指向具体候选或成片文件；迟到的编辑不能写到刚切换的新版本。旧版本记录保留。
- 样片用于检查叙事与节奏，不冒充实际视频生成质量；缺图、缺声音与待生成素材明确显示。
- 批量清单复用实际输入准备与任务 journal，预检本身不提交模型。确认之后仍复查；输入变化需要重新审查。
- 已知价格可显示，未知价格明确标注；复杂平台计价继续后置。调用次数不伪装成实际扣费账单。
- 时间码意见和交付版本保存在项目中，随命名检查点和项目包保留；恢复为副本不继承原机器活动任务。

## 2026-10-18 序列与节奏样片的编辑 / 播放隔离

序列和节奏样片生成前后均以双击进入对应编辑器；已有视频结果的封面分别提供「播放成片」「播放样片」独立按钮，提示分别为「双击编辑序列」「双击编辑节奏样片」。保留 Generator 的显式编辑入口。普通视频和音频仍双击播放。

画布覆盖层排除这两种节点的双击播放，并监听统一的 `sequence` 状态：任意 `openSequence` 入口进入编辑都会调用播放器释放流程（暂停、移除 `src`、重新 `load()`、移除 DOM）。编辑器打开期间不能重新创建画布播放器。播放按钮隔离指针、单击和双击；播放器同时吞掉连续点击的第二下，防止封面按钮被播放器替换后误点静音或暂停。

验证使用本地 FFmpeg 合成的 30 秒带音轨 MP4，不调用生成平台。新增 `e2e/sequence-activation.spec.ts`，覆盖生成前后双击、独立按钮单击 / 双击、键盘触发 Generator 编辑（排除画布 pointerdown 提前停播造成的假通过）、播放时双击另一序列进入编辑、节点位置不变和普通视频 / 音频回归。持有旧媒体 DOM 引用核对 `paused === true`、`src` 已移除且 `isConnected === false`。
