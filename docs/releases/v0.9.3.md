本版补齐火山方舟 Agent Plan 的内置智能体与语音模型接入，并进一步修复视频参考素材的引用身份。

## 新增

- **Agent Plan 内置智能体**：可选择套餐内的 Doubao Seed、DeepSeek、GLM、Kimi 等文本模型，支持连续工具调用、跨轮历史和思考内容续传。套餐文本仅用于内置智能体。
- **Agent Plan 语音**：接入语音合成 2.0 和语音识别 2.0，使用套餐专属 Key 与路由；合成支持预置音色、语速和 MP3 / WAV，识别支持全文与分句时间戳。
- **自动获取套餐模型**：可选填写模型目录 Access Key / Secret Key，获取官方支持模型列表，并使用缓存与手动刷新。无需查询目录时可继续使用内置模型。

## 修复

- 修复视频提示词引用可能静默指向另一份素材的问题：引用绑定到具体来源和素材，调整输入顺序时自动映射，素材删除、替换或协作冲突时阻止使用失效引用；上游文本中的引用同样校验。
- 修复引用候选的输入刷新失败提示不准，以及禁用候选仍可被键盘选中的问题。

## 使用说明

Agent Plan 语音的实际可用性取决于账号的语音权限及套餐抵扣设置；语音合成与识别尚未在真实平台完成成功产物和识别准确率的验收。内置智能体已用真实套餐 Key 验证多轮对话、连续工具调用和思考续传。
