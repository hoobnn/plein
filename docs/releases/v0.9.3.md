本版补齐火山方舟 Agent Plan 的内置智能体与语音模型接入，并进一步修复视频参考素材的引用身份。

## 新增

- **Agent Plan 内置智能体**：可选择套餐内的 Doubao Seed、DeepSeek、GLM、Kimi 等文本模型，支持连续工具调用、跨轮历史和思考内容续传。套餐文本仅用于内置智能体。
- **Agent Plan 语音**：接入语音合成 2.0 和语音识别 2.0，使用套餐专属 Key 与路由；合成支持预置音色、语速和 MP3 / WAV，识别支持全文与分句时间戳。实际可用性取决于账号的语音权限及套餐抵扣设置。
- **自动获取套餐模型**：可选填写模型目录 Access Key / Secret Key，获取官方支持模型列表，并使用缓存与手动刷新。无需查询目录时可继续使用内置模型。

## 修复

- **视频素材引用身份**：提示词引用绑定到具体来源和素材；调整输入顺序时自动映射，素材删除、替换或协作冲突时阻止使用失效引用，避免引用静默指向另一份素材。上游文本中的引用同样校验。
- **引用候选状态与键盘操作**：修正输入刷新失败提示和禁用候选的键盘交互。

## 验收范围

Agent Plan 内置智能体已用真实套餐 Key 验证两轮对话、5 次顺序工具调用及思考续传。TTS 被平台以套餐抵扣未开启拒绝，ASR 握手成功后收到业务拒绝；按用户要求跳过未开通能力，没有变更云端设置。语音成功产物与识别准确率尚未完成真实验收。
