本版让新用户更容易上手：空画布可以直接插入短剧模板或让小满来搭，首次进入画布有快捷键提示，分镜表的主按钮会跟着进度提示下一步；设置里可以从备份恢复数据；方舟的按量对话模型新增 DeepSeek、GLM、Kimi。

## 新增

- **空画布起点**：空画布上新增「短剧模板」和「让小满帮我搭」。插入模板后会选中剧本并打开创作引导；选小满会预先填好一句创意请求，你补完再发。
- **快捷键提示条**：第一次进入画布时，顶部会显示一条快捷键提示（右键拖动平移、添加节点、命令面板），关闭后不再出现。
- **重新打开新手引导**：命令面板和设置里都能重新打开新手引导。
- **从备份恢复**：「设置 → 数据与备份」可以选一份备份来恢复。恢复前会先自动备份当前数据，完全退出并重新打开 Plein 后生效；生效前可以取消，被替换下来的原数据保留在 `maintenance/replaced` 里。
- **方舟按量对话模型**：方舟按量渠道新增 DeepSeek V4 / V4.1、GLM-5.3 Flash、Kimi K3.1 Pro。

## 优化

- **分镜表主按钮随阶段变化**：主按钮会按当前进度依次显示「展开为镜头」「批量出分镜图」「批量生成视频」「批量配音」；提示词默认折叠，点开后失焦会自动收起，主动展开的保持展开。
- **小满示例跟着画布变**：小满给出的示例会随画布状态变化；需要你补内容的示例只填进输入框，不会直接发送。
- **设置分区整理**：本机 AI、技能与画布能力、MCP、插件这些技术分区收进「高级」。只在本地检查配置的平台，连接测试后显示「已填写，未验证」，第一次生成时才会真正验证密钥。
- **失败恢复更简单**：任务失败后默认只显示「再查一次」，手动填任务 ID 和用当前 Key 重新提交收进了「高级选项」。
- **界面术语统一**：界面里统一使用「文本生成」「序列」「分组框」这几个说法。
- **模型目录更新**：方舟和百炼的模型目录随上游声明一起更新，包括方舟套餐与百炼 Token Plan 渠道的模型。

## 修复

- 修复各平台「获取密钥」链接没有直达创建 API Key 页面的问题。
- 修复首页引导已打开时，再次打开新手引导会叠出两层的问题。
- 修复创作引导还没挂载时，「创作下一步」的打开请求会丢失的问题。
- 修复分镜表作用范围内还有未展开的镜头时，主按钮没有显示「展开为镜头」的问题。
- 修复从备份恢复时暂存路径分隔符不一致的问题；现在会清理残留的暂存，并限制替换下来的数据保留份数。
- 修复空画布模板、小满入口和分镜折叠开关的无障碍名称读错的问题。

## 使用说明

从备份恢复会替换当前全部数据（项目、素材和平台密钥），只有完全退出并重新打开 Plein 后才生效。方舟新增的 DeepSeek、GLM、Kimi 按量模型按方舟的按量价格计费，尚未在真实平台上验收。
