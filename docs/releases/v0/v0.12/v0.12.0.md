> [!NOTE]
> 可以自动更新。旧版生成的对外 MCP 令牌升级后保留为一枚全权限令牌，已接入的外部 AI 不用改配置；建议到设置页按需改为更小的权限范围。

本版大幅扩充对外 MCP 入口，外部 AI 可以把文件送进画布、取出成品，并按权限范围分别授权；小满和外部 AI 新增模型切换、估价、影响面板、分镜逐镜修改等工具。参考模式会自动写好各平台的素材说明，节点生成面板的位置与各类面板、对话框的尺寸也统一了一遍。

## 新增

- **MCP 令牌按权限管理**：设置页可以生成多枚对外令牌，每枚有名称、读取 / 编辑 / 运行 / 删除四类权限和每日运行上限，可单独撤销。旧版的单个令牌升级后保留为一枚全权限令牌。
- **外部调用的确认、幂等与撤销**：外部 AI 发起花钱或删除类操作时会先返回待确认，带确认重试后才执行；同一请求重复发送只执行一次；修改类操作返回撤销凭据，可按次撤销。运行节点时可以推送进度。
- **外部文件进出画布**：外部 AI 可以用 `import_asset` 从 base64、网址或本机路径导入文件，也可以申请一次性上传地址；`download_asset`、`get_asset` 与导出序列工程会返回短期有效的下载地址，本机模式还能直接保存到指定目录。
- **服务端切宫格与生成蒙版**：外部 AI 可以用 `split_grid` 切分宫格图，切分规则与界面一致；用 `create_mask` 按矩形或多边形生成局部重绘蒙版，也接受导入的蒙版图片。
- **外部入口管理画布**：外部 AI 可以新建、列出、重命名、删除项目和画布，但不能删除你正在看的画布；还能清空选区、调整打开中画布的视口。
- **更多 Agent 工具**：
  - `list_models`、`set_node_model` 查看模型目录并切换节点模型，参数按新模型自动校正。
  - `estimate_cost` 运行前估价。
  - `get_impact`、`keep_stale`、`revoke_keep`、`run_impact` 操作影响面板。
  - `get_shots`、`edit_shots` 逐镜读取和修改分镜表。
  - `delete_results` 删除历史候选。
  - 平台与默认模型设置工具，密钥不会出现在返回结果里。
  - `rename_element` 改名时同步更新所有 @ 引用。
  - `rewrite_prompt` 新增结构、详略和目标模型选项，生成模型与输入上下文会自动带上。
- **参考素材说明自动生成**：参考模式下，最终提示词开头会按目标平台的写法自动列出每个素材的作用（方舟中文作用行、MiniMax 英文职责行、万相「图N / 视频N」），同一角色的多张图合并成一行，正文里已经写明的编号不再重复。资产卡绑定也改为各平台推荐的写法。实际输入预览与发给平台的文本一致。
- **提示词改写按平台公式**：通用改写按「主体、动作、场景、光影、运镜、风格、画质、约束」组织；目标是 MiniMax H3 多模态参考时改用六段结构。正文里的素材编号会原样保留。
- **对话节点模型参数**：对话节点可以设置模型声明的专属参数，如推理强度、回答详略、联网搜索。
- **图片节点种子**：模型支持时图片节点显示种子，并按声明的范围校验。
- **文生视频连了素材时提示**：文生视频模式下连入的图片、视频、音频不会送进模型，面板会提示并给出切换到图生视频或参考模式的按钮。

## 优化

- **生成面板位置统一**：节点生成面板下方放得下就放下方，否则放上方；两边都放不下时相机平滑平移到能同屏显示。平移会稍等片刻再开始，双击、拖动不会被打断。
- **面板与对话框尺寸成体系**：右侧面板宽度、对话框宽高和窗口断点统一成固定几档，窄窗口（900 以下）右侧面板铺满。工具条放不下时自动换行，禁用态和键盘焦点环统一。
- **参数表单更完整**：对象类参数渲染成可折叠的子表单，需勾选启用；多选枚举渲染成多选框；开区间范围参与校验。视频分辨率和画幅的选项按当前模式收窄，换模式时自动纠正。
- **提示词与参考区布局**：提示词输入区高度统一，辅助区不再嵌套滚动，小窗口也能看全一行参考缩略图。面板最小可用高度提高到 400。
- **设置、序列编辑器与各面板打磨**：设置页平台行按钮、开关对齐，内容列放宽；序列编辑器在小窗口下可整体滚动，检查器用「镜头 01 · 视频」代替内部 ID；素材、资产库、检查点、快捷键与创作引导多处细节调整。
- **首页**：从模板新建的项目沿用模板名；一分钟内的时间统一显示「刚刚」。
- **modelbay 升级到 0.2.2**：
  - 方舟视频引用写法改为 `@图片N`、`@视频N`、`@音频N`，旧写法 `@imageN` 等仍能识别。
  - 万相 3.0 引用写法改为「图N / 视频N / 音频N」，并支持百炼提示词改写。
  - Seedance 2.5 新增输出格式选项。
  - `z-image-turbo` 单次只出 1 张。
  - MiniMax H3 不再支持「仅尾帧」模式，面板里该模式不可选。

## 使用说明

外部 AI 生成视频、调用插件能力和所有删除类操作需要你确认；生成图片、文本、配音不单独确认，也没有内置智能体每轮的运行次数上限，要限额请在生成令牌时填写每日运行上限。`import_asset` 的网址来源会拒绝内网地址，本机路径限于用户主目录。界面动作（选区、视口）需要该画布已在应用里打开才会生效。

本版新增的 MCP 工具与参考素材说明已通过本地自动化测试，尚未在真实平台上逐项验收。
