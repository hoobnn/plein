本版是 0.3.0 的修复版，修正画布手感和界面细节上的几个问题。

## 修复

- 修复主线程卡顿、多个移动事件被合并处理时，松手后的惯性速度成倍虚高、画布被甩得过远的问题；渲染较慢时快速甩动松手也能正常带惯性。
- 修复按钮在悬停期间换了图标（例如开始生成后变成停止），指针移开后提示不收起的问题。
- 修复在角色档案里添加服饰、表情时，新出现的名称框被滚动区裁掉一截的问题。
