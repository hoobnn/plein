本版把各模型平台的接入统一换成 modelbay，模型目录、参数范围和模型状态都跟官方文档对齐；同时修复审片窗口里视频播放的几个问题。

## 优化

- **模型平台接入统一**：火山方舟（按量与套餐）、阿里云百炼、MiniMax、豆包语音、OpenAI 与 OpenAI 兼容渠道都改由 modelbay 提供请求构造、参数校验和任务轮询。各模型的参数上下限、默认值和上下线状态以官方文档为准，设置页和使用方式不变。
- **模型目录跟上官方**：
  - OpenAI 新增 GPT Image 2.6 的两个模型。
  - 方舟套餐里官方已不再列出的 `minimax-m3`、`kimi-k2.7-code` 不再出现。
  - 豆包语音 `seed-tts-1.0` 重新出现在目录里。
  - 百炼里 plein 暂时跑不通的模型不进目录，包括 `qwen3-asr-flash`、`wan2.2-s2v`、`happyhorse-1.0-video-edit`，以及必须指定音色的 `cosyvoice-*`、`qwen-audio-*-tts-*`。
- **历史模型归档**：官方归为历史或已下线的模型不再支持。MiniMax 的 `MiniMax-M2.7`、`music-3.0`、`music-2.6` 已归档，画布里引用它们的节点仍能打开，但不能再运行，请换用其他模型。
- **参数不支持时直接提示**：OpenAI 生图收到模型不支持的参数时会报错说明，不再静默丢弃。

## 修复

- 修复审片窗口里单击视频不能播放、暂停的问题；现在单击切换播放和暂停，双击也不会进入全屏。
- 修复关闭审片后马上重新打开，会带回上次平移和缩放状态的问题。
- 修复关闭审片后视频或音频仍在后台播放的问题。
- 生成请求不再带上协作文档里可能夹带的平台回调地址。
- 更新依赖，修复 7 项依赖安全审计问题。
