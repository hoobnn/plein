本版新增复制画布、把画布移动到其它项目，小满也能按你的要求撤销或重做画布操作。内置智能体更稳了：遇到限流或超时会自动重试，长任务不容易撑爆上下文，运行中发的消息会排队送达。

## 新增

- **复制画布与移动画布**：编辑器顶部「项目 / 画布 ▾」菜单新增「复制当前画布」和「移动到…」。副本带上全部内容和已有生成结果，可以继续运行，原画布不受影响。外部 AI 和小满可以用 `duplicate_canvas`、`move_canvas` 完成同样的操作。
- **小满撤销 / 重做你的操作**：你明确要求时，小满可以用 `ui_undo` 撤销或重做画布上的操作，一次最多 20 步。它和 ⌘Z 用的是同一个撤销栈，由你最近操作过的画布窗口执行。
- **运行中发消息改为排队**：内置智能体正在工作时发的消息会排队（最多 5 条），在下一步送进本轮，不用等它做完再说。
- **批量运行与批量取出**：新增 `run_nodes`，一次运行指定的多个节点；`download_asset` 可以一次取出多个素材。
- **项目包导出与导入**：小满和外部 AI 可以通过扩展操作导出、导入项目包。

## 优化

- **模型下拉显示平台名**：内置智能体的模型下拉会在标题后带上平台名，方舟按量和 Agent Plan 里的同名模型能分清。
- **自动重试**：内置智能体调用模型遇到限流、超时或服务暂不可用时，会等待后自动重试最多 3 次；第一步收到空回复时也会重试一次。
- **长任务更耐用**：工具返回的内容过长时保留开头，提示小满分页读取，不再整段丢弃；本轮上下文快超预算时，先压缩较早的工具结果。图片超出预算、调用了不存在的工具，都会作为结果回给小满，由它自己调整，不再直接中断这一轮。还剩 3 步时小满会收到收尾提醒。
- **读取更快**：同一次回复里连续的只读工具调用会并行执行。
- **小满面板布局**：标题栏不再换行挤压，选区标签可以换行，审批和权限下拉与输入区对齐。

## 修复

- 修复小满面板上下文用量显示超过 100%（如 128%）的问题；现在按内置智能体实际的上下文预算计算。
- 修复固定视频素材的替换提示仍指向旧工具的问题；现在指向 `edit_sequence`。

## 使用说明

复制画布时不带检查点、撤销历史和 Agent 对话。复制那一刻还在运行的任务，在副本里记为「已取消」，不会重新提交，也不会重复计费。素材文件不另外复制，副本和原画布共用。副本里原有的人工确认和交付记录会标为「历史」，需要重新核对。首页只有项目卡片，复制和移动入口目前只在编辑器里。

`ui_undo` 只有你明确要求时才会用；要撤销小满自己这一轮的改动，仍用「撤销这一轮」。它需要该画布已在应用里打开。

本版新功能已通过本地自动化测试，尚未在真实平台上逐项验收。
