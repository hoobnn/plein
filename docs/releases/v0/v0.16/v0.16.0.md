本版改了 @ 角色时带图的方式：默认只带真正需要的那一张，想多带几张可以在参考图下直接点角色名勾选。同时精简了生成面板里参考图和 @ 引用的显示，提示词里只显示你写的原文，参考图下的名字和 @ 写法一一对应。

## 优化

- **@ 角色默认只带需要的图**：只写 `@角色` 时带角色卡第一张（全身定妆图）；写了档案项（如 `@叶舒/少年/校服`）时只带命中的时期、服饰、表情图，没有命中时带第一张。场景、道具卡不变。
- **选图改为多选，入口就在参考图上**：参考图下的角色名显示送入数和可选数（如「叶舒 1/3」），点名字或 ⋯ 菜单即可打开这个角色的选图，点一张加一张、再点去掉，送入顺序按角色卡顺序。选图面板写明当前是自动、已选几张还是仅文字，可一键恢复自动；设成仅文字的角色在参考列表末尾留有入口。
- **提示词里的 @ 引用只显示原文**：不再叠加「图2+2」这类编号和截断的名字；编号放进悬停提示并完整写出，如「叶舒 → 图2、图3、图4」。
- **参考图标注更简洁**：参考图下的名字优先用提示词里的 @ 写法；同一来源连续几张只写一次名字；去掉每张图下的「连线 / @ / 角色」标签，来源改在悬停提示和 ⋯ 菜单里显示；⋯ 按钮放到缩略图上，悬停时出现。

## 修复

- 修复确认参考素材期间参考图整排上下跳动的问题；选图时弹层不再跟着抖动，取消勾选第一张时弹层也不会被关掉。

## 使用说明

升级后，已经生成过、@ 了角色且没有手动选过图的节点，送入的图会变少，会被标为「需要重跑」，下游显示「上游已改」。不想重跑的可以在「查看影响」里选择保留；想恢复原来的效果，在该角色的选图里把需要的图勾上即可。
