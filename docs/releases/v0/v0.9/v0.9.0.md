本版可以从平台官方拉取最新模型列表并合并进模型目录，兼容渠道的模型 ID 也能从列表里选；平台密钥改为卡片式配置，校验状态按密钥组区分；桌面端支持启动时检查更新并可调整检查频率。同时补齐各平台新版模型并标出弃用模型，数据维护遇到符号链接时会安全跳过，界面的间距、字号和行高统一过一遍。

## 新增

- **远端模型列表**：火山方舟、阿里云百炼和 MiniMax 可从官方接口拉取模型列表，按平台和 Key 缓存后合并进模型目录。保存设置后会在后台自动拉取，完成后刷新目录和候选；设置页和生成器都会显示合并结果和列表覆盖范围。
- **兼容渠道的模型候选**：只要填了 Base URL 和 API Key，兼容渠道就能拉取模型列表，作为模型 ID 输入框的候选，仍可手动输入。
- **平台密钥卡片**：每个平台的密钥以卡片展示，带校验状态；未配置的平台按所需字段排好密钥输入与校验入口，支持组合鉴权。平台图标换成彩色图标，设置窗口加大，内容区收窄到便于阅读的宽度。
- **桌面端更新检查**：可在设置里开关启动时检查更新，并调整自动检查的频率。
- **模型目录更新**：按官方文档补齐火山方舟新版对话模型、MiniMax M3.1，复核豆包语音模型；百炼按官方要求限制素材。弃用和下线中的模型仍保留，标明「弃用」及说明并排到选择器末尾，不会成为默认模型。

## 优化

- **参考图与首帧提示**：运行详情补充图片参考与提示词提及的对应关系；首帧模式会说明参考图没有送入模型，分镜表标明图生视频的首帧输入，首帧为空时不显示提示。
- **界面统一**：对话框、提示条、表单、画布浮层、流程表、侧栏、生成器参数弹层、便签、资产库、动作面板和设置页统一使用同一套间距、字号、行高和圆角。
- **数据维护**：备份、清理和恢复遇到符号链接时跳过，不再整体停止，跳过的条目记入备份清单，并在数据维护页列出；无法读取的目录也会跳过并上报。

## 修复

- 修复数据维护可能跟随符号链接移动、删除或备份数据目录以外文件的问题：移动、恢复、删除前逐层检查路径，回收站到期删除同样会检查。
- 修复后台拉取模型列表时的问题：轮询会阻塞保存，删除密钥组后不刷新，切换上下文仍显示旧候选，以及服务端超时后界面没有刷新。
- 修复密钥组的校验结果没有按组区分，没有密钥组的平台校验失败不更新状态徽章，以及密钥输入框提前收起的问题。
- 修复很短的密钥在掩码中会露出字符的问题；读取平台配置时增加所有者校验。
- 修复桌面端更新的问题：下载报错后自动检查不再恢复，手动检查后启动检查重复执行，偏好写盘失败仍显示保存成功；桌面设置改为原子写入。
- 修复场景准备里分镜表和镜号排序与其他分镜列表不一致的问题。
- 修复部分提示和冲突块因样式类未定义而没有颜色的问题。

## 使用说明

远端模型列表需要已配置并能通过校验的 Key；拉取失败时继续使用内置目录。只在拉取列表里、没有内置到 Plein 的模型，只能用于对话。
