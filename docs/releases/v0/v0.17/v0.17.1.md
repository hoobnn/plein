本版让外部 AI 助手通过 MCP 操作即梦草稿、查找画布和跟踪单次生成任务，也修复了重试可能重复提交付费请求的问题。

## 新增

- **即梦草稿协作**。助手可以查看即梦全能画布和短剧项目，逐卡比较差异，按你确认的范围导入、同步或发布素材。写入回执给出实际项目和两端的卡片 ID，方便核对同名卡片。
- **查找和打开画布**。助手可以按标题搜索项目和画布，在后台读写指定画布。需要切换时，可以只打开指定窗口；没有打开的窗口时，会返回画布链接。
- **跟踪指定任务**。助手可以逐项查看批次里哪些镜头使用了缓存、哪些还需复核，也能用运行 ID 查看当时的输入、继续等待或取消那次生成。

## 优化

- **从空工作区开始**。还没创建画布时，助手也能查看可用工具、节点和模型，预览项目包并导入第一张画布。较长的 3D 构图参数说明可以分页读全。
- **令牌权限和用量更清楚**。只读令牌可以查看选区和视野。改变选区或移动镜头需要编辑权限。每日上限按运行工具的调用次数计算，重启后保留。

## 修复

- 修复部分模型请求已受理或受理状态未知时，使用同一请求 ID 重试可能再次提交的问题。现在会返回原回执，便于继续核查。
- 修复提示词改写期间手动编辑的文字可能被覆盖的问题。现在保留你的编辑，并单独返回生成的草稿。
- 修复首次设置所有者账号后，原项目、检查点素材或已生成的文件可能无法找到的问题。切回免登录模式后，原有 MCP 令牌可继续使用。

## 使用说明

即梦协作需要在运行 Plein 的电脑上登录对应的官方 CLI。提示词改写的预览和写回都会调用模型。此次测试通过本地模拟平台核对了提交与恢复流程，真实即梦账号写入和供应商扣费尚未验收。详见[智能体与 MCP 指南](https://github.com/hoobnn/plein/blob/v0.17.1/docs/guide/agent.md)。
