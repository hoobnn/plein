本版重做生成节点的参考素材面板，统一提示词正文里的图片、视频和音频编号，并接入 OpenAI 官方接口、按模型完善生成参数与界面控件。

## 新增

- **OpenAI 官方接口**：在「设置 → 模型平台 → OpenAI」填写官方 API Key 即可接入，无需填写 Base URL。对话使用 Responses API，提供 GPT-6 系列模型，支持图片输入、流式文字、工具调用、JSON Schema 输出和内置智能体，思考强度可选 low / medium / high。图片提供 GPT Image 2.5 生成与多参考图编辑，支持画幅、张数、格式、画质和透明背景，局部重绘可用蒙版指定编辑区域。
- **图片生成参考素材**：生成图片节点可以用连线或 @ 名称引用参考图，多图按实际送入顺序对应编号；调整顺序后引用跟随素材身份，不会换到另一张图。

## 优化

- **参考素材唯一列表**：生成节点顶部只保留一份「参考素材」列表，按服务端确认的送入顺序展示图片、视频和音频，各类各自从 1 编号，图片编号与最终提示词一致；每项带名称、媒体类型和来源角标（连线、@、角色、续镜）；首帧、尾帧模式下，图片标注「首帧」「尾帧」用途，不显示平台编号。连线素材可拖拽排序、替换、移除和预览；只靠 @ 送入的素材不参与排序，提供「定位到画布」。提示词下方原有的「引用」栏和重复的图列表已移除。
- **未送入原因**：已连线或已绑定但没有送入的素材收进「未送入」折叠区，逐条写明原因，包括连了但未送入、@ 断链、同名不明、超出上限、当前模型或模式不支持该媒体、残留绑定；同一引用只列一次，同一张卡的不同视角或档案项分别列出；可从条目定位到画布或断开。
- **提示词正文统一编号**：最终提示词直接写平台编号，图片节点用「图N」，MiniMax 视频的图片、视频、音频分别写「图片N」「视频N」「音频N」，其余视频写「@imageN」「@videoN」「@audioN」；图片元素只写编号，资产卡写成「名字（编号）」，原文已写同名时只补编号，避免重复。旧的 @imageN / @videoN / @audioN 写法按同类素材当前的送入顺序解析，越界或身份对不上时在提交前拦下，提示从参考素材重新选择。编号按最终送入顺序重建，不再追加「参考对应」表，画布原文保持不变。
- **引用徽标**：提示词里的 @ 引用按媒体类型显示为对应编号的徽标，后面用淡色显示去掉扩展名的素材名；短名称和长文件名都不会裁掉编号，悬停可看到名称与编号。断链、同名不明或未送入的引用使用警示样式，并显示原因。
- **长提示词编辑区**：生成节点面板加宽到 960，高度随窗口增长（上限 720）；提示词编辑区至少 12 行并占住面板主体，更长时在框内滚动；参考素材区最高占 45% 并在内部滚动，上传工具行固定在顶部。
- **实际输入精简**：只展示模型、字数（字符限制说明收进信息标记）、最终提示词全文（可复制）、参数摘要和送入张数；参考素材统一看顶部，不再重复列出图片与引用。
- **图片参数按模型开放**：图片分辨率、画幅、单次张数和组图参数按模型显示，切换模型自动校正不支持的值，界面、实际输入预览和提交前使用同一份校验。MiniMax image-01-live 增加画风与权重，百炼图片支持自定义宽高，万相视频支持自动时长并校验参考视频时长。
- **界面控件统一**：下拉、开关、滑块、分段控件、弹层、对话框和提示气泡统一圆角、间距与配色；长下拉选项可换行显示。
- **弹层动效**：菜单、下拉、对话框等浮层统一进出场动画，按实际弹出方向播放；系统开启「减少动态效果」时立即显示、不做动画，设置变化即时生效；动效资源加载失败时直接显示浮层，不影响操作。
- **参考图拖动换序**：拖动换序支持 Esc 取消，取消不改顺序；松手后落在瓦片上的点击不会误开预览，撤销一次即可恢复原顺序。

## 修复

- 修复给视频、音频素材起名后无法用 @ 名称引用的问题；视频和音频可以像图片一样被引用，顶部列表与提示词徽标按媒体类型显示对应编号。
- 修复文生视频模式下连线的图片不会送入模型却没有任何提示的问题；这类图片列入「未送入」并说明原因，不阻断生成。
- 修复对话、局部重绘、图片精修等不接收参考图的节点，@ 了有图的资产卡却没有任何提示的问题；现在会说明当前节点不会送入 @ 引用的参考图，并列出连线送入的媒体。
- 修复多个可选参考超出模型上限时逐条重复提示的问题；同类超限合并为一条，并列出没有送入的素材名。
- 修复普通文字里的 @ 被误判为断链引用、以及 @ 后多打一个空格时引用被漏掉的问题。
- 修复重名引用序号越界时预览直接不可用的问题；预览照常显示，提示该改成哪种写法，改不了的引用在最终提示词里保留原文。
- 修复参考图上游生成失败时提示不指明来源的问题；提示写明是哪个上游节点失败，没有名字的节点显示节点类型。
- 修复复制粘贴资产卡和生成节点后，副本丢失选图配置、资产卡丢掉原来的参考图连线的问题；同画布内副本接回原上游并保持顺序，跨画布或上游已删除时不补线。
- 修复项目包导入后名称绑定和选图失效的问题；导入时按新元素重映射，未映射的外部引用保持不变。
- 修复删除元素或断开参考连线后，残留的必需参考和选图仍然阻断预览、继续显示的问题；这类残留只在读取时忽略，仍被 @ 引用的配置保留。
- 修复 MiniMax 超宽画幅被压缩变形的问题；21:9 等超宽比例按模型实际支持范围提供。
- 修复窗口较矮时素材选择列表连一项都放不下的问题。
- 修复画布内节点卡片、播放器和节点编辑器的圆角与画布渲染卡片不一致的问题。
- 修复媒体渲染相关依赖中的已知安全问题并同步升级；旧版源工程仍可正常恢复。

## 使用说明

「设为必需参考」已从「实际输入」移到参考素材：已送入的素材在素材菜单里设置，未送入的在「未送入」里设置，同一条引用只在一处修改。必需参考优先占用名额，缺图或放不下时不会提交。

编号在每次预览和执行前按最终送入顺序重建，图片、视频、音频各自从 1 编号，只写入最终提示词，不写回画布原文。旧的 @imageN / @videoN / @audioN 写法按同类素材当前的送入顺序解析，越界或素材已经换掉时预览照常显示，提交前会拦下并提示该改成哪种写法；上游文本里的 @ 引用只解析一次。元素已删除、或既没有连线也没有被 @ 的残留绑定会被忽略并列入「未送入」，不再阻断生成；模型不支持视频或音频参考时，这类素材也列在「未送入」并说明原因。

OpenAI 在「设置 → 模型平台 → OpenAI」填写官方 API Key 后启用，不需要 Base URL。「测试连接」只调用只读的模型列表接口，验证网络与鉴权，不生成内容，不能代替具体模型的权限、余额和实际生成验证。对话与图片生成按所用平台规则计费；图片单次 1–10 张、最多 16 张参考图，提示词最多 32000 字符，单张输入限制 14 MiB，当前不提供分辨率档位与 seed。「刷新模型列表」只展示账号返回的 ID，目录外条目不会自动开放生成。局部重绘会把白色编辑区域转换成透明蒙版，蒙版只作为编辑引导，不保证边界和未选区域逐像素不变。首批不包含 OpenAI 视频、语音与实时音频；生成请求不自动重试，断流、缺少结束事件或无有效图片结果时保留「提交未知」状态。OpenAI 接入尚未使用真实 Key 完成云端生成验收。

本版的模型参数调整未新增真实账号的产物验收；实际可用性仍取决于账号权限、余额和平台返回。
