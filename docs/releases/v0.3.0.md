本版主题是**稳定连续生产**：生成结果不丢、提交状态说得清、长时间开着画布不变慢，并补齐了素材、角色、检查点和剪辑里的大量细节。

## 生成与平台

- **提交结果更可靠**：MiniMax、火山方舟、百炼已发出的提交遇到超时或 5xx 时记为「提交结果未知」，不再当作失败自动重提；请求关联 ID 在发出前先落盘，人工补提交会保留原来那次未知尝试，方便核对费用。
- **大文件结果不丢**：同步返回的大文件先持久暂存再入库，入库失败或进程退出后可以恢复，不必重新生成；完整备份会带上这些暂存文件。
- **等待阶段可见**：任务显示平台已受理、平台排队、生成中等实际阶段，平台没给出阶段时不会假装在排队。
- **权限说明更诚实**：「连接检查通过」只代表配置和连接正常，设置页会注明尚未验证具体模型、资源权限或余额。

## 素材与角色

- 导入 **DOCX / TXT** 参考正文：拖入、粘贴或上传 `.docx`，正文转成可编辑的 Markdown 卡片，小满可以分页读取。
- 角色资产按用途分为**全身定妆图、肖像／半身图、情绪九宫格、角色设定图**四类，加「其他参考」，共最多 24 张；旧角色的图片自动归类，无需重新上传。放到画布时按顺序连入角色卡。
- 跨项目资产列表显示来源项目，编辑时可选择是否保留原归属。
- `@` 引用改为轻量色块，⌘／Ctrl 点击定位到元素；邮件地址里的 `@` 不再被当成引用，需要原样写出时用 `\@名称` 或 `@@名称`。
- 视频支持**像素裁剪**（媒体工具 → 裁剪），生成出来的视频结果也能直接用媒体工具加工，源文件保留。

## 画布与检查点

- 工具栏单击即可在移动与抓手工具之间切换，与 V／H 快捷键同步。
- 大画布「适应画布」能完整显示所有元素，缩放低于 1% 时显示小数比例。
- 分镜卡片排版更紧凑；生成失败的说明在媒体底图上保持可读；被遮挡的隐藏端口不再抢占拖动。
- 检查点只读预览可拖动、缩放、触屏捏合，随窗口尺寸自动适应；列表分页加载，删除前确认。
- 修复 Linux 浏览器里按中键平移、松手时把剪贴板内容贴进画布的问题。
- 协作中对方升级版本时，当前画布即时切换为只读并说明原因。
- 包含分镜表的画布顶部提供「创作下一步」引导；分镜数据异常时列出原始行号和无效字段，不会静默删掉坏行。

## 剪辑与样片

- 序列和节奏样片双击进入编辑，封面上的「播放成片」「播放样片」按钮单独播放，互不干扰。
- 时间线支持 Home／End、方向键逐帧、空格播放；只读画布也能打开序列预览。
- 字幕空文本和无效时间就地提示；素材信息读取失败可单独重试。
- 「导出工程」先校验 ZIP 再交给浏览器下载，可取消、可重试；导出失败时可展开查看完整原因。

## 稳定性与性能

- 显卡上下文丢失并恢复后，画布自动重绘，不再一直空白。
- 静止的画布也会执行 GPU 资源回收：千张素材的画布操作后静置，JS 堆从约 256 MB 回落到约 59 MB。
- 媒体预览着色器精简，多个画布引擎共用同一份预览程序。
- 修复原生输入框里多行替换后撤销／重做会清空或重复正文的问题。
- 智能体面板的对话记录支持键盘翻页，分行底栏不再挡住收起按钮。
