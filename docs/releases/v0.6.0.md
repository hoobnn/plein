本版加入制作总览与逐镜创作工作台，串起原文映射、镜头状态、参考分析、剪辑与交付检查；同时扩展视频参考、创作配方和音色创建能力，并补齐 3D 构图预演、全景视角与高级媒体加工。

## 新增

- **制作总览与逐镜工作台**：集中查看制作目标、分镜进度、候选和交付状态，从总览定位到具体镜头；记录原文映射、制作决策与连续性观察，保留版本和来源。
- **逐镜头表格与三阶段制作流程**：在分镜表按行编辑时长、画面、景别、光影、对白、音效和运镜，运镜支持预设与自定义描述；顶部可切换镜头确认、资产准备和提示词合成，合成提示词只补空白字段，不调用生成平台。
- **3D 构图动态预演**：人物站位、朝向和机位可按时刻独立编辑，本机播放查看白模运动，支持时间轴与局部撤销；截图保存完整轨迹与时刻，兼容原有静态构图。
- **全景浏览与命名视角**：把 2:1 等距柱状全景图放入场景后可转动朝向和俯仰预览，从选定视角重新投影出图片并追加到视角档案；通过画布中的版本同步后可用 `@场景名/视角名` 引用。
- **高级视频加工**：选中视频后可做区域修补（本地插值）和片段替换，用矩形四周的背景填补画面区域，或把另一段等长片段按原画幅放入指定区间；两者都保留原音轨与时长，产物来源随画布、撤销、检查点和项目包保存。
- **按语音分句准备切分**：选中音频后可创建语音识别草稿，识别结果核对后可转成可编辑的自定义区间，再执行本地切分；实际切分支持 2–20 段。
- **角色图片制作与候选归档**：从已保存角色建立独立的图片草稿，采用候选后可归档到指定角色槽位并单独设置封面；归档绑定角色与具体候选，冲突时要求重新核对。
- **场景视角档案**：场景可保存命名机位与描述，每个视角独立保存参考图，普通保存、同步和项目包都会保留全景来源。
- **剪辑内生成候选与单实例返工**：从可靠来源复制当前输入到独立草稿，比较候选后明确替换选中的剪辑实例，保留剪辑与声音关联。
- **批量清单统一审核**：助手与界面共用分镜批量预检，生成前可核对目标、复用、跳过和阻塞原因；输入变化后重新检查，避免沿用过期确认。
- **本地拉片与 AI 分析草稿**：对本地视频拆镜、提取媒体证据，按镜头生成可编辑的分析与文字归纳；保留本地结果、引用和失败状态，便于逐项核对。
- **独立剪辑实例**：同一素材可多次放进序列，分别修剪和编辑字幕；交付记录保留源素材区间，便于从成片追溯镜头与生成段。
- **成片技术检查**：对实际输出文件检查媒体轨道、字幕范围及黑场、静音等问题，分别显示发现问题、未检查和检查失败。
- **多模态视频参考**：扩展 MiniMax 与火山方舟的视频参考输入，完善首尾帧、图片、视频、音频的模式校验、参考编号和素材传输。
- **创作配方与模板**：增加可核对输入的创作配方库、首页短剧模板入口，支持插件提供节点组模板并完整插入画布。
- **音色设计与复刻**：分开提供豆包、MiniMax 的音色设计、声音复刻和已有音色登记；补齐豆包图片设计与后付费音色，以及 MiniMax 增强参考和可选音频处理，保存可用的试听资产。
- **模型与本机插件配置**：支持显式配置的兼容对话渠道；本机插件包安装前可查看检查结果，安装后默认禁用，由用户决定何时启用。
- **助手扩展画布操作**：助手可读取剪辑实例、审片记录、制作目标、来源与连续性、模板、拉片结果和任务恢复等画布信息，也能保存工作流模板、归档全景视角与角色图片；付费操作与删除沿用确认模式，助手的计划与推断不会写成用户确认。

## 优化

- 为模型渠道加入品牌图标，便于识别平台。
- 完善视频参考的格式、时长、比例和模式冲突提示，在提交前给出可操作的修正信息。
- 完善制作记录在刷新、复制、项目包迁移和检查点恢复时的来源追溯；历史内容确认不会自动恢复生成执行授权。
- 完善字幕与交付出处记录，减少同一素材多次剪辑时的状态混用。
- **素材加工与创作工具入口**：媒体工具按本地处理、AI 草稿和提示词配方分组，汇集图片精修、宫格切分、首帧视频、取帧续镜与音频切分，并说明各项操作的能力边界。
- **卡片下方的节点编辑器**：编辑器固定在对应卡片下方，不再随边缘空间压缩或翻到上方；顶部集中显示上传、画布参考和参考缩略图，底部单行排列模型、模式、参数和生成操作。
- **实际素材引用**：顶部参考素材以服务端准备的实际输入为准，按图片、视频、音频各自编号；可用分类搜索的行内引用菜单接入已有素材，续镜接续帧固定为首张参考。
- **画布平移与菜单**：按住右键拖动可平移整张画布，右键轻点仍打开快捷菜单；拖动后不再误弹菜单。
- **工作台与空画布入口**：重排参考资产、镜头脚本和候选预览，加入镜头导航、会话内草稿保留与并发冲突保护；为空画布提供只建不跑的创作入口。
- **面板与窄窗口交互**：打磨长标题、设置导航、下拉选项和提示气泡的边界布局，保持关闭与取消入口可达。
- **引导页加载**：首页不再为引导页加载完整设置模块，减少首次打开的脚本体积。

## 修复

- 修复助手指定素材加工时被误判「来源已变化」的问题；加工期间元素换了素材仍会拒绝写回画布。
- 修复助手扩展操作中的素材 id 未编码，携带 `../` 或 `?` 时可能访问到未登记接口的问题。
- 修复素材裁剪从画面边缘开始时参数被误判不合法的问题。
- 修复续镜「换成新画面」在首帧图片缺失时仍改写来路的问题；首帧图片不在时明确拒绝换画面。
- 修复 AI 拉片作业轮询可能一直空转的问题；改为按作业 ID 精确读取并设等待上限，读不到时按状态未知收场，不继续提交剩余作业。
- 修复助手构图截图结果只保留 8 条，服务端还没取走就被挤掉而只能等待超时的问题。
- 修复桌面片段替换的末帧时长被写成零的问题。
- 修复只保留加工产物时，原素材和片段替换输入没有跟着画布与检查点保留的问题。
- 修复归档确认时沿用已变化的制作类别的问题。
- 修复从同一帧新建素材草稿时可能创建失败的问题；只读或锁定的来源不再允许派生。
- 修复角色选图与续镜接续帧的实际输入不一致的问题。

## 使用说明

音色创建、视频生成和 AI 分析由所选平台提供服务，并按平台规则计费。AI 草稿和自动技术检查供创作时核对；本版的本地工程验收不代表真实平台生成质量、跨镜连续性或创作效率已经得到验证。
