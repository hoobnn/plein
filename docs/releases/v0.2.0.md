> [!NOTE]
> Plein 目前处于测试迭代阶段，版本之间的数据格式和交互仍可能调整，重要项目请定期导出项目包备份。
>
> 应用标识在本版变更，此前的 0.1.x 安装包已下架，也可能无法自动更新过来：装过的请手动下载本版覆盖安装，数据目录不变。

本版让生成更可控、返工更精准：生成前可以核对实际输入，改动后只重做受影响的节点，失败时不会重复计费；同时加入项目包、按能力设置的默认模型、五轨剪辑和角色档案。

## 新增

- **实际输入预览**：生成前列出所用模型、展开 `@` 后的提示词、实际送入的参考图，以及超出模型上限放不下的参考图。参考图超限时先保角色、再场景和道具；可以把某张卡标为必需参考。
- **查看影响**：改了剧本、台词、参考图或换了候选之后，列出受影响的节点、原因和建议（重做 / 审查 / 保留），只重做勾选的，其余结果原样保留；能沿用的候选直接沿用，不重复花钱。保留的决定会被整组运行跳过。
- **失败恢复**：提交结果未知、轮询或下载失败时不自动重复提交，避免重复计费。任务面板给出重新获取、填平台任务 ID 续查、确认未受理后重提等处理方式；生成期间改了输入，晚到的结果只进候选，不覆盖当前结果。
- **项目包**：首页导出整个项目（`.plein`），在另一台电脑或数据目录导入；导入前校验版本和文件哈希，列出缺失的模型、音色和插件。
- **修改方案**：智能体或外部应用（经 MCP）先列出要改的字段、要重做的节点和预计调用次数，按「只改文字 / 只出候选图 / 全部」的范围批准。
- **默认模型**：设置 →「模型平台」顶部可以给每种能力指定默认模型，新建节点直接带上，节点上可以另选。打开旧画布时，模型留空的节点补成当前默认模型，已有结果不会因此过期。
- **多轨剪辑**：序列编辑器改为画面、对白、音效、配乐、字幕五条轨的时间线，支持拖动排序、修剪入出点、逐帧定位和缩放；提供逐段转场与变速、原声音量、配乐闪避与响度标准化，预览按导出时间线播放，字幕和导出同字体同效果。
- **剪辑工程导出**：导出 OTIO / FCPXML / SRT 剪辑工程，连同素材打包。
- **角色档案**：角色可记录时期、服饰、表情和次音色，资产库编辑页改成档案式。
- **道具抽取**：抽取角色场景时也抽出关键道具，场景、道具卡同样配参考图。
- **plugin-sdk 0.1.2**：新增可选的模型版本与价格、按幂等键查任务、提交结果未知等声明，均为新增字段，旧插件不受影响。详见[插件文档](https://github.com/hoobnn/plein/blob/main/docs/dev/plugins.md)。

## 优化

- **不再自动选模型**：启用新平台不会悄悄更换已选模型。
- **参考图缺失时照常生成**：`@` 引用的卡片参考图出不来时，镜头只带文字设定照常生成。
- **更新下载进度**：桌面端下载更新时显示进度和速度。

## 修复

- 修复平台请求被 5 分钟的响应头超时掐断的问题。
- 修复序列整条静音时导出失败的问题。
- 修复画布加载失败时不显示真实原因的问题。
