本版加入动态合成本地渲染与可追溯源工程，支持跨画布复用源版本、从带来源的视频继续编辑，以及透明叠加轨和动画字幕；同时加快首次进入画布，限制长会话缓存，完善场景视角与创作面板的反馈，并修复成片检查、服务重启和画布删除等问题。

## 新增

- **动态合成本地渲染**：新增动态合成节点，提供片头章节卡、角色介绍和视频标题包装模板；可编辑文字、样式和出现时间，选择横竖画幅、时长与分辨率，在本机预览并渲染成视频，明确采用候选后再接入剪辑。
- **可追溯源工程**：渲染结果保存源工程、完整参数、输入素材和版本清单；检查点、项目包与剪辑工程附源都会保留来源依赖，便于回查和继续制作。
- **跨画布源版本复用**：历史结果可转成普通视频，素材库可列出同一产物的多个源版本，选定后放入其他画布；旧源恢复为独立副本，不覆盖当前工程。
- **从视频继续编辑**：带有动态合成来源的普通视频可恢复可编辑节点和原素材连线；保留原视频，一次撤销可移除恢复出的整个副本。恢复时复查画布、视频与来源身份，避免写入已经变化的目标。
- **透明视频与叠加轨**：动态合成支持输出带透明通道的 WebM；剪辑序列可添加独立视频叠加层，编辑时间、入点、速度、位置、尺寸、不透明度和前后顺序，按全片时间摆放或锚定镜头随重排移动。叠加视频不另加声音，预览与导出共用时间线，素材不足或失效时说明原因并拦截导出。
- **动画字幕与字幕工程导出**：字幕可选择普通烧录、整句淡入或弹出动画，也可关闭画面烧录并保留字幕文件；工程导出附带独立叠加素材、字幕时间与来源，以及可离线打开的字幕源工程。
- **场景视角缺失提示**：场景卡片补充视角与视角图数量摘要；放入画布时检查缺失或类型不符的视角素材，说明缺失数量及影响，助手放置场景也会收到检查结果。

## 优化

- **首页与画布首开**：引导、确认框和编辑面板按需加载，本轮拆包使首页初始脚本压缩体积由约 252 KiB 降至约 158 KiB；移除进入画布时额外的加载等待，指向或聚焦项目卡片时提前准备编辑器。加载中显示占位，模块失败提供重试或刷新恢复入口。
- **长会话内存与素材查询**：限制素材元信息缓存，及时回收已删除正文的缓存和不再引用的视频尺寸数据，减少长时间编辑时的内存积累；合并一页素材的来源统计与摘要查询，减少逐项读取。
- **生成与任务反馈**：生成、提示词优化与翻译、检查点入口说明禁用原因；旧失败或取消任务标注「已有更新的运行」，解释为何不能直接重试旧记录。首次实际输入预览立即读取，后续编辑保留防抖，切换目标后中止过时请求。
- **角色档案与归档**：自定义名称按整份档案查重并点名占用者，显示时期与服饰上限；角色图片归档冲突按具体原因说明，可在弹层内重新读取角色后继续。
- **校验与失败反馈**：平台配置和维护设置按字段显示校验原因；导入文件时说明支持格式及网络失败原因，蒙版保存失败时在弹窗内提示重试并保留绘制内容；资产库保存、删除和收藏失败也给出明确的重试指引。
- **读取与操作状态**：构图预览失败可原地重试，音色列表与选择器显示读取和重试状态，成片回看显示实际文件的加载状态；侧栏区分资产库正在读取、首次失败与缓存未更新。本机插件启用、停用、重载与扫描完成后显示结果，首页新建失败时将错误提示滚入视野。
- **画布与参数编辑**：侧栏打开时以可见画布中心缩放，整理还原提示在悬停、键盘聚焦或只读期间暂停消失；侧栏搜索按 Escape 先清空再收起。全景参数允许暂存未完成的数值草稿，确认时再归一化；媒体时长未知时不再允许无效拖动定位。
- **费用核对**：批量预检按币种分别展示估算，沿用候选不计入新生成费用，未知价格单独提示。

## 修复

- 修复成片检查时音视频诊断输出偶发交错、少解析视频帧，导致正常文件被误判检查失败或未检查的问题。
- 修复服务重启时旧连接仍访问已关闭数据库、会话接口返回 500 的问题；先排空在途请求与连接，再关闭数据库。
- 修复删除当前画布后沿用过期清单选错去向，以及请求完成前离开又返回同一画布时被迟到导航接管的问题；删除后读取最新清单，并复查当前访问身份。
- 修复旧客户端保存场景时未带视角字段、已有视角被清空的问题；视角截图已删除、不是图片或原文件缺失时，生成前拦截并提示重选；视角名称与自身旧名重复不再被误判为歧义。
- 修复输入法组字期间 Enter、Escape 或空格误触提交、关闭浮层或画布抓手的问题；内层已经处理的 Escape 不再继续关闭外层。
- 修复平台设置因字段顺序或无效数字草稿一直显示未保存、连接检查被锁住的问题，以及会话就绪后最近模型记录未重新读取、只剩最后一项的问题。
- 修复关闭重开检查点后可重复发起同一次恢复，以及历史素材同帧重复导入、等待期间切为只读仍继续写入的问题；失败保留选择并释放等待状态，便于重试。
- 修复剪辑音频读取未及时取消、异常波形结果留在缓存、过期时间线仍可激活，以及协作更新后的样片设置可能覆盖新值的问题。
- 修复无关维护操作失败时清掉已有素材清理预览的问题；只在清理本身失败时作废对应预检。
- 修复助手清空选区后仍显示空区域、技能选用失败仍关闭窗口，以及复制失败却提示成功的问题。
- 修复跨画布创作引导偏好串用、项目索引重试读取错误目标，以及画布变为只读后仍采用提示词建议的问题；仅有计划差异时不再把同步入口藏进空态，本地拉片依据失效后不再显示其他来源的归纳。
- 修复连接令牌保存失败却提前改变内存状态、迟到的旧状态覆盖新结果的问题；保存成功后再更新，并取消过时读取。
- 修复构图预览初始化失败后残留绘制资源、同帧截图可能重复上传的问题；失败后可重新加载最新场景，截图中显示忙碌状态。

## 使用说明

动态合成在本机渲染，需要预先准备兼容的本机浏览器；桌面包附带媒体工具和字体，不自动下载渲染浏览器。源版本恢复要求兼容的模板与渲染版本，不能把任意视频还原为工程；不兼容或缺少原素材时保留视频并说明原因。剪辑工程中的动画字幕附带源文件，不转换为其他剪辑软件的原生字幕效果。
