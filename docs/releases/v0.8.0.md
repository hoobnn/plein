本版支持同一平台保存多组 Key 并按标签切换，任务、配音和音色会自动用对 Key，Key 变动时提前说明影响并给出可行的出路；新增火山方舟 Agent Plan 平台与多家对象存储，加入 3D 构图与 Blender 互通、场景机位与走位准备；镜头工作台、分镜表和创作引导围绕「一镜一镜做好」重新整理，并修复多处状态误报。

## 新增

- **同一平台多组 Key**：每个平台可添加多组 Key 并设置标签（如「个人」「团队」），一键切换当前使用的一组；平台列表直接显示当前组。原有配置自动成为「默认」组，只有一组时界面与之前一致。
- **任务与音色自动用对 Key**：已提交的生成任务在轮询、重启恢复和取消时始终使用提交时的那组 Key，切换当前组不会影响它们；用复刻或设计的音色配音时，自动使用音色所属的那组 Key。音色旁标出所属 Key，所属 Key 已删除或已更换时会提示并排到选择列表末尾。
- **Key 变动前说明影响**：每组 Key 显示还有多少任务待取回、绑定了多少音色；删除前说明后果，替换正在使用的 Key 前提醒，并可一键「改为添加新组」保留原组。
- **火山方舟 Agent Plan**：新增独立平台，使用套餐专属 Key，提供套餐内的 Seedream 与 Seedance 模型。视频参考存储新增阿里云 OSS、腾讯云 COS 预设和自建 S3 兼容存储，已有 TOS 配置不受影响。
- **3D 构图与 Blender 互通**：构图面板改为全屏，可下载 Blender 插件，把人物、场景件、机位和预演关键帧导出到 Blender，再把渲染的图片或视频导回画布作为独立素材。插件只读取所选的本地文件，不联网。
- **场景机位与走位准备**：汇总当前画布各分镜表里场景的命名视角、未指定视角和错误引用，按镜号列出逐镜站位、走位和姿势，可直达镜头工作台或编辑视角。
- **逐镜准备清单**：分镜表按镜头列出缺失项并可定位到字段，支持按场景和缺失筛选、批量选择可见镜头；次要操作收进「更多」菜单。
- **镜头衔接意见**：镜头工作台的「上一镜结束 → 本镜开始」对照区可直接记录衔接问题，细分到服装、朝向、位置、光线和动作；意见记在本镜已采用的候选上，换候选后提示重新审阅，分镜表准备清单会标出需修改的衔接。
- **豆包声音复刻 1.0**：支持用已有的复刻 1.0 音色合成；旧配置仍默认使用 2.0，资源与音色不匹配时提示核实版本。
- **导演分镜准则**：分镜生成与智能体的分镜规划按镜头目的、首帧衔接、轴线与正反打、单一主运镜、表演反应链和台词时长等准则逐列填写，手改过的列默认保留。

## 优化

- **镜头工作台**：按候选状态只给一个主操作（生成镜头图、生成视频、采用或审阅）；摘要标注素材是否实际送入模型、仅有文字设定或已人工认可；对照区展示相邻镜头画面与状态，宽屏两栏并排，支持键盘切镜。
- **分镜表**：表头对照制作目标显示时长区间，并提示计划偏短或偏长；已确认的计划按字段记住，只有计划本身变化时才重新提示差异；可把镜头、配音和音效关联到画布中已有的序列，从分镜表打开节奏样片后可返回。
- **创作引导**：改为步骤视图，每步一行显示状态，当前步骤只保留一个主操作；试做按选镜头、核对输入、生成采用、人工审阅、做样片的顺序展示，并提供固定段试做和无序列交付的直接入口。
- **短剧模板**：未指定时长时先按约 40–60 秒的短场景组织剧本与分镜，强调可见动作和连续性；角色与场景抽取补充固定造型、声音表演和空间机位。
- **输入预览**：批量计划明细按实际送入模型的首帧和参考素材计数，不再把未送入的引用算作输入；序列与节奏样片显示「本地处理」。
- **配音绑定**：分镜配音音色按台词说话人映射，多句不一致时单独提示。
- 按节点类型调整节点下方编辑面板的尺寸。

## 修复

- 修复 Key 失效后的任务无法恢复的问题：结果已存到本地的可直接取回；无法取回时可确认后用当前 Key 重新提交（写明会再次计费），或标记已处理。字幕识别同样适用；配音任务提示改用其他音色或重新复刻。
- 修复两个窗口同时编辑同一平台时，只改 Key 也会把另一窗口刚保存的设置覆盖回旧值的问题。
- 修复上游重新运行期间，下游的旧结果不再提示「上游已改」的问题。
- 修复镜头工作台和分镜表的状态误报：展示节点没有候选时误报阶段不一致，查看其他阶段节点或其他候选时仍可写入衔接意见，尾帧无法对应到所属视频候选，以及失焦时读到旧的镜头快照。
- 修复分镜表筛选边界和选择范围错误，以及逐句配音绑定检查不准确的问题。
- 修复场景准备中的镜头跳转提示、不唯一引用重复分组、错误视角重复归入「未指定」，以及编辑视角没有跟随最新资产关联的问题。
- 修复创作引导在任务读取中、任务未确认、未选代表镜头和输入变化时状态推导不准，提前开放做样片或显示错误提示的问题。

## 使用说明

多组 Key 的切换作用于整个平台，不按节点或项目单独选择。升级前已提交、尚未完成的任务没有记录所用 Key，会按当前组继续查询，建议等这些任务完成后再切换。Blender 插件需在 Blender 中手动安装。
